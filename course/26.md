# Python для веба

## Браузер и сервер
Браузер отправляет HTTP-запрос по URL. Сервер выбирает обработчик и возвращает ответ: HTML, JSON, файл или сообщение об ошибке. Python часто используется на сервере. HTML описывает структуру страницы, CSS — внешний вид, JavaScript — поведение в браузере.

## Flask
Flask — небольшой веб-фреймворк. Установи его в окружении через python -m pip install Flask. Следующий пример сохрани как web_app.py и запускай отдельно в терминале: встроенный запуск книги ограничен по времени и не предназначен для постоянного сервера.
```python
from flask import Flask
app = Flask(__name__)

@app.get("/")
def home():
    return "<h1>Привет из Python!</h1>"

@app.get("/hello/<name>")
def hello(name):
    from markupsafe import escape
    return f"Привет, {escape(name)}!"

if __name__ == "__main__":
    app.run(host="127.0.0.1", port=5000)
```
Открой http://127.0.0.1:5000 в браузере. @app.get связывает адрес с функцией. <name> — переменная часть пути. escape превращает специальные символы пользовательского текста в безопасное HTML-представление. Сервер останавливается Ctrl+C в терминале.

## Шаблоны
Рядом с web_app.py создай папку templates и файл home.html внутри неё:
```html
<!doctype html>
<html lang="ru">
<meta charset="utf-8">
<title>Моя книга</title>
<h1>Привет, {{ name }}!</h1>
<ul>{% for topic in topics %}<li>{{ topic }}</li>{% endfor %}</ul>
</html>
```
Обработчик страницы может вернуть render_template("home.html", name="Аня", topics=["Списки", "Функции"]). render_template нужно импортировать из flask. Jinja подставляет переменные и по умолчанию экранирует значения в HTML-шаблонах. Общий каркас страниц можно вынести в базовый шаблон через extends и block.

## Формы и статические файлы
CSS и изображения обычно кладут в static. URL для них строят через url_for("static", filename="style.css"). HTML-форма отправляет данные через GET или POST. В Flask поля доступны через request.args для параметров URL и request.form для полей формы. Проверяй полученные значения перед расчётами и сохранением.

## Локальная разработка и публикация
Локальный сервер доступен только на твоём компьютере, пока выбран 127.0.0.1. Встроенный сервер Flask предназначен для разработки. Инструкции старого курса по Heroku исторические: для настоящей публикации понадобятся актуальный хостинг и подходящий сервер запуска. Для обучения сначала добейся правильной работы локально.

## Практика
1. Запусти локальную страницу с приветствием.
2. Создай маршрут /about с описанием проекта.
3. Передай список тем в шаблон и выведи его циклом.
4. Сделай форму имени и приветствие; не вставляй пользовательский текст в HTML без экранирования.
