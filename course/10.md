# Циклы: повторяем без копирования кода

## for перебирает элементы
```python
for fruit in ["яблоко", "груша", "банан"]:
    print(fruit)
```
На каждом шаге очередной элемент попадает в переменную fruit. Затем выполняется блок с отступом. Имя переменной выбираешь ты.

## range и подсчёт
```python
for number in range(1, 6):
    print(number)
total = 0
for number in range(1, 101):
    total += number
print(total)  # 5050
```
range(5) даёт 0, 1, 2, 3, 4. range(1, 6) — числа от 1 до 5. Правая граница не включается. Третий аргумент задаёт шаг: range(10, 0, -2) даёт 10, 8, 6, 4, 2. Нулевой шаг запрещён.

## while повторяет, пока условие истинно
```python
count = 3
while count > 0:
    print(count)
    count -= 1
print("Старт!")
```
Не забудь менять значение, от которого зависит условие, иначе получится бесконечный цикл. Здесь запуск автоматически останавливается через несколько секунд; кнопка «Стоп» тоже завершает процесс.

## break, continue и else
```python
for number in range(1, 10):
    if number == 3:
        continue      # пропустить остаток этого шага
    if number == 6:
        break         # закончить весь цикл
    print(number)
```
else после цикла выполняется, если цикл закончился без break. Это удобно при поиске.
```python
for number in [1, 3, 5]:
    if number % 2 == 0:
        print("Нашли чётное")
        break
else:
    print("Чётных нет")
```
pass — пустая инструкция-заглушка. Она не пропускает шаг и не завершает цикл.

## Индексы, пары и вложенные циклы
```python
for index, name in enumerate(["Аня", "Илья"], start=1):
    print(index, name)
for key, value in {"чай": 120, "хлеб": 50}.items():
    print(key, value)
for row in range(2):
    for column in range(3):
        print(row, column)
```
enumerate даёт номер и элемент. Цикл по словарю без items перебирает ключи. Во вложенном цикле внутренний полностью отрабатывает для каждого шага внешнего. Не удаляй элементы списка во время прямого перебора: перебирай копию или собирай новый список.
