# Пакеты и pip

## Стандартная библиотека и внешние пакеты
math, json и pathlib уже входят в Python. pandas, requests, Flask и BeautifulSoup нужно установить отдельно. pip — менеджер пакетов, который скачивает и устанавливает такие библиотеки. Название при установке может отличаться от имени при import: beautifulsoup4 устанавливается, bs4 импортируется.

## Сначала виртуальное окружение
Хотя в исходном курсе окружения обсуждаются в главе 23, пользоваться ими стоит уже сейчас. Все команды этого раздела выполняются в терминале, а не в редакторе Python. Установка требует интернета.
```text
python -m venv .venv
```
На Windows после этого:
```text
.venv\Scripts\python -m pip install requests
```
На macOS и Linux:
```text
.venv/bin/python -m pip install requests
```
На macOS/Linux первую команду обычно запускают через python3. Такой способ не требует активации: мы явно выбираем Python нужного окружения. Чтобы книга использовала установленные пакеты, запусти app.py именно этим интерпретатором.

## Полезные команды pip
```text
python -m pip --version
python -m pip list
python -m pip show requests
python -m pip install requests
python -m pip uninstall requests
python -m pip freeze > requirements.txt
python -m pip install -r requirements.txt
```
Здесь python должен означать выбранный интерпретатор окружения; можно заменить его полным путём выше. freeze фиксирует установленные версии. Для нового проекта лучше устанавливать только нужное, а не копировать все пакеты из чужой системы. Обновление выполняется с --upgrade.

## HTTP-запрос с requests
Пример требует requests и доступа к сети. Сеть здесь используется только при явном запуске этого примера.
```python
import requests
try:
    response = requests.get("https://httpbin.org/json", timeout=5)
    response.raise_for_status()
    data = response.json()
    print(data)
except requests.RequestException as error:
    print("Запрос не удался:", error)
```
status_code показывает статус, text — текст ответа, json() разбирает JSON. raise_for_status сообщает об HTTP-ошибках. timeout ограничивает ожидание; без него программа может ждать слишком долго.

## Свой пакет
Папка mypackage с __init__.py и модулями внутри может служить пакетом. Например, mypackage/arithmetic.py содержит add, а from mypackage.arithmetic import add импортирует функцию. Публикация собственного пакета — отдельная тема, для первых упражнений не нужна.

## Практика
1. Узнай версию pip и путь выбранного Python.
2. Создай окружение и установи requests.
3. Сохрани список зависимостей в requirements.txt.
4. Создай чистое второе окружение и установи зависимости из файла.
5. Учебное задание во вкладке практики работает без внешних пакетов; оно не проверяет установку pip автоматически.
