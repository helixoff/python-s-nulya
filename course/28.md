# API: программы общаются с программами

## Что такое API
API — договор о способах обращения к программе. HTTP API определяет адреса, методы, формат запросов и ответов. Если сайт — интерфейс для человека, то API часто служит интерфейсом для другой программы.

Представь сервис книг. GET /books получает список, GET /books/7 — одну книгу, POST /books создаёт новую, PATCH /books/7 меняет часть полей, DELETE /books/7 удаляет запись. PUT обычно заменяет представление ресурса целиком. Это распространённые соглашения, а точные правила задаёт документация конкретного API.

## Статусы HTTP
- 200 OK — запрос выполнен.
- 201 Created — создан новый ресурс.
- 204 No Content — успешно, тела ответа нет.
- 400 Bad Request — запрос некорректен.
- 401 Unauthorized — нужна действительная аутентификация.
- 403 Forbidden — доступ запрещён.
- 404 Not Found — ресурс не найден.
- 429 Too Many Requests — слишком много запросов.
- 500 Internal Server Error — ошибка сервера.

## JSON и проверка данных
```python
import json
response_text = '{"books": [{"id": 1, "title": "Python"}]}'
data = json.loads(response_text)
for book in data["books"]:
    print(book["id"], book["title"])
```
Успешный HTTP-ответ ещё не гарантирует нужную структуру данных. Проверяй типы и обязательные поля. Не все ответы являются JSON: иногда сервер присылает HTML-страницу ошибки.

## Запрос из Python
При установленном requests и доступе к сети:
```python
import requests
response = requests.get(
    "https://httpbin.org/get",
    params={"topic": "python", "page": 1},
    timeout=5,
)
response.raise_for_status()
data = response.json()
print(data["args"])
```
params формирует параметры URL. Для POST с JSON используют json={...}. Заголовки передаются через headers={...}. API-ключи берут из переменных окружения, а не вписывают в публичный файл. Для учебного примера httpbin ключ не нужен.

## Пагинация и ограничения
Большие списки обычно возвращают частями: страницами или курсорами. Пока документация не говорит об окончании, нужно запрашивать следующую часть. Не угадывай формат курсора. При 429 учитывай Retry-After. Повторение POST без защиты от дубликатов может создать несколько записей.

## Практика
1. Придумай адреса и методы API для списка задач.
2. Разбери JSON с книгами и выведи только названия.
3. Обработай отсутствие ожидаемого поля.
4. Запиши, чем отличаются 400, 401, 403 и 404.
