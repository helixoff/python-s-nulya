# Функции, которые работают с функциями

## Функция тоже значение
Функцию можно сохранить в переменную, передать другой функции и вернуть как результат. Функцию, которая принимает или возвращает функции, называют функцией высшего порядка.
```python
def double(x):
    return x * 2

def apply(function, value):
    return function(value)

operation = double
print(apply(operation, 5))
```
double без скобок — сама функция. double(5) — её вызов и результат. Это различие важно для сортировки, обработчиков кнопок и других событий.

## map, filter, reduce
```python
from functools import reduce
numbers = [1, 2, 3, 4]
print(list(map(lambda x: x * 2, numbers)))
print(list(filter(lambda x: x % 2 == 0, numbers)))
print(reduce(lambda total, x: total + x, numbers, 0))
```
map преобразует каждый элемент. filter оставляет те, для которых правило истинно. reduce сворачивает последовательность в один результат, постепенно объединяя накопленное значение с очередным элементом. Здесь sum(numbers) был бы проще. map и filter возвращают итераторы, поэтому для печати всего результата мы превращаем их в list.

## Замыкание
```python
def make_multiplier(factor):
    def multiply(value):
        return value * factor
    return multiply

triple = make_multiplier(3)
print(triple(7))
```
Внутренняя функция помнит factor из окружения, в котором была создана. Это называется замыканием. Не нужно заучивать определение: проследи, откуда берётся число 3.

## Декоратор
Декоратор оборачивает функцию дополнительным поведением: например, пишет сообщение перед вызовом.
```python
from functools import wraps

def announce(function):
    @wraps(function)
    def wrapper(*args, **kwargs):
        print("Начинаю")
        return function(*args, **kwargs)
    return wrapper

@announce
def greet(name):
    return f"Привет, {name}"

print(greet("Аня"))
```
@announce примерно равнозначно greet = announce(greet). *args и **kwargs передают произвольные аргументы дальше. wraps сохраняет имя и документацию исходной функции. Несколько декораторов применяются снизу вверх.

## Практика
1. Преврати список строк с числами в числа через map(int, ...).
2. Отбери города, названия которых длиннее пяти букв.
3. Найди сумму списка обычным циклом, sum и reduce.
4. Напиши функцию, возвращающую функцию прибавления заданного числа.
5. Добавь декоратор, печатающий «Готово» после успешного вызова функции.
