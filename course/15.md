# Ошибки Python: читаем сообщения без паники

## Как читать traceback
Если программа остановилась, читай последнюю строку сообщения: там тип ошибки и причина. Выше указаны файл, номер строки и путь вызовов. Найди ближайшую строку своего кода, затем проверь значения переменных перед ней.

## Частые ошибки
- SyntaxError — Python не смог разобрать запись: пропущены скобка, кавычка или двоеточие.
- IndentationError — неверные отступы.
- NameError — имя ещё не определено или написано с ошибкой.
- IndexError — нет такого индекса в последовательности.
- KeyError — нет такого ключа в словаре.
- TypeError — действие не подходит к типу или переданы неверные аргументы.
- ValueError — тип подходящий, но значение недопустимо.
- AttributeError — у объекта нет такого метода или свойства.
- ModuleNotFoundError — не найден импортируемый модуль.
- ImportError — модуль найден, но нужный объект импортировать не удалось.
- ZeroDivisionError — деление на ноль.
- FileNotFoundError — не найден файл по указанному пути.

## Отличаем тип от значения
```python
age = "25"
print(int(age) + 1)
```
"25" + 1 вызвало бы TypeError: нельзя сложить строку и число. int("кот") вызвало бы ValueError: строка есть, но число в ней не записано. int("25") работает.

## Пошаговая диагностика
```python
prices = [50, 120]
index = 1
print("Список:", prices)
print("Индекс:", index, "Длина:", len(prices))
print(prices[index])
```
Если index был бы 2, произошло бы обращение к третьему элементу, которого нет. Последний допустимый положительный индекс равен len(prices) - 1.

## Отладка — проверка гипотез
1. Прочитай точное сообщение.
2. Найди строку.
3. Выведи важные значения через print и type.
4. Уменьши пример до нескольких строк.
5. Исправь одну причину и запусти снова.

## Не все ошибки приводят к остановке
```python
width = 5
height = 3
area = width * height
assert area == 15
print(area)
```
Если случайно написать width + height, программа выполнится, но ответ будет неверным. Это логическая ошибка. assert помогает проверить ожидания при разработке; для проверки пользовательского ввода используй обычные if, потому что assert можно отключить.

## Практика
1. По очереди намеренно вызови NameError, IndexError, KeyError и ZeroDivisionError. Каждый пример запускай отдельно.
2. Исправь сложение "5" + 2 так, чтобы получить число 7.
3. Найди ошибку в формуле площади прямоугольника width + height.
4. Запиши в заметки три ошибки, которые встретились тебе, и способ исправления.
