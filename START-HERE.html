Python с нуля

Настольная книга с настоящим Python, заданиями и заметками. Всё основное работает без интернета. Учись в своём темпе — дедлайна нет.

Сначала распакуй весь ZIP-архив в обычную папку. Не запускай файлы прямо внутри архива. Папки course и original должны остаться рядом с app.py.

Windows

  1. Установи Python 3.11 или новее с python.org. В установщике включи Add python.exe to PATH; компонент Tcl/Tk должен быть установлен.
  2. Открой распакованную папку и дважды щёлкни START-Windows.bat.
  3. Откроется книга. Выбери первую главу и вкладку «Урок».

Если запуск не получился, открой терминал в папке книги и выполни py -3 app.py. Если команды py нет — python app.py.

macOS

Установи Python с python.org вместе с Tkinter. В терминале перейди в папку книги: введи cd , перетащи распакованную папку в окно терминала и нажми Enter. Затем:

python3 app.py

После разрешения запуска исполняемых файлов можно использовать START-macOS.command. Если Finder запрещает запуск, используй команду выше; менять системные настройки безопасности не нужно.

Linux

Установи Python 3 и Tkinter средствами своей системы. В Ubuntu/Debian обычно:

sudo apt install python3 python3-tk

Из папки книги запусти python3 app.py или sh start-linux.sh.

Как пользоваться

  1. Читай главу. Зелёная ссылка над примером открывает код в редакторе.
  2. Перейди во вкладку «Практика» и реши задание. «Запустить» выполняет код; «Проверить вывод» сравнивает результат с ожидаемым.
  3. Для input() заранее заполни поле входных данных: одно значение на строку.
  4. Если не получается, открой подсказку. Решение доступно в меню «Ещё».
  5. Пиши заметки и отмечай главу пройденной. Всё сохраняется автоматически. Черновики разных заданий хранятся отдельно.

Запуск ограничен 8 секундами и 64 КБ вывода, чтобы случайный бесконечный цикл не зависал. Долгие программы и веб-серверы сохраняй через «Ещё → Сохранить код» и запускай отдельно. Пользовательский код имеет обычный доступ к файлам компьютера.

Прогресс и перенос на другой компьютер

Меню «Данные → Экспорт» сохраняет резервную копию с кодом, заметками и отметками. На другом компьютере открой «Импорт». Файлы, созданные упражнениями в папке практики, переноси отдельно. Удаление распакованной книги не удаляет прогресс: он хранится в пользовательской папке приложения.

Можно читать сразу

Открыть всю книгу без установки Python. Эта версия предназначена для чтения и печати, код в ней не выполняется. В браузере нажми «Печатать / сохранить в PDF».
