# Переменные и встроенные функции

## Переменная — имя для значения
Представь подписанную коробку. Надпись age помогает найти нужное значение. В Python переменная — имя, связанное с объектом. Значение вычисляется справа от знака =, а имя записывается слева.
```python
name = "Аня"
age = 25
height = 1.68
is_student = True
print(name)
print(age + 1)
```
В строке age = 25 мы сохраняем число 25 под именем age. print(age) выводит содержимое, а print("age") — само слово age.

## Имена
Используй латинские буквы, цифры и подчёркивание. Имя не может начинаться с цифры. first_name понятнее, чем x. Python различает age и Age. Не называй переменные print, list или str: это имена полезных встроенных функций.
```python
first_name = "Иван"
last_name = "Петров"
country, city = "Россия", "Казань"
year = 2026
year = year + 1
print(first_name, last_name, year)
```
Переменную можно связать с новым значением. В year = year + 1 сначала берётся прежний year, к нему прибавляется 1, результат сохраняется под тем же именем.

## Встроенные функции
Функция получает данные в скобках и что-то делает или возвращает результат. print печатает, len считает элементы, type определяет тип, abs находит модуль числа, round округляет, min и max выбирают границы, sum складывает.
```python
print(len("Python"))      # 6 символов
print(abs(-7))            # 7
print(round(3.14159, 2))  # 3.14
print(min(4, 8, 2))       # 2
print(max(4, 8, 2))       # 8
print(sum([4, 8, 2]))     # 14
```
help(print) показывает справку, dir(str) — доступные свойства и методы строк. Не нужно запоминать весь список: пользуйся справкой по мере необходимости.

## Преобразование типов
```python
age_text = "25"
age = int(age_text)
price = float("19.90")
label = str(age)
print(age + 1)
print("Мне " + label)
print(int(3.9))  # 3: дробная часть отбрасывается
```
int превращает подходящий текст в целое число, float — в дробное, str — в текст. int("кот") вызовет ValueError: такой текст не является числом. int("3.9") тоже не сработает; сначала нужен float. Для дробей в коде используют точку, а не запятую.

# Операторы: считаем и сравниваем

## Арифметика
Оператор — знак, который выполняет действие над значениями. + складывает числа, - вычитает, * умножает, / делит с дробным результатом, // делит с округлением вниз, % возвращает остаток, ** возводит в степень.
```python
print(7 / 2)    # 3.5
print(7 // 2)   # 3
print(-7 // 2)  # -4, округление именно вниз
print(7 % 2)    # 1
print(2 ** 3)   # 8
print((2 + 3) * 4)  # 20
```
Скобки задают порядок. Без скобок умножение выполняется раньше сложения. Для практических расчётов полезнее понятная формула со скобками, чем головоломка из операторов.

## Короткое присваивание
```python
score = 10
score += 5   # то же, что score = score + 5
score -= 2
score *= 3
print(score)  # 39
```
Есть также /=, //=, %= и **=. Никакого отдельного оператора ++ в Python нет.

## Сравнения возвращают bool
```python
print(5 == 5)   # True: равно
print(5 != 3)   # True: не равно
print(5 > 3)    # True: больше
print(5 <= 3)   # False: меньше или равно
age = 20
print(18 <= age < 65)
```
True означает истину, False — ложь. Одно = присваивает, два == сравнивают. Строки тоже можно сравнивать, но "10" и 10 — разные значения разных типов.

## Логика: and, or, not
```python
age = 20
has_ticket = True
print(age >= 18 and has_ticket)  # оба условия истинны
print(age < 18 or has_ticket)    # хотя бы одно истинно
print(not has_ticket)           # отрицание
```
and — «и», or — «или», not — «не». В логических условиях пустая строка, пустой список, число 0 и None считаются ложными. Остальные непустые значения обычно истинны. and и or могут возвращать сами операнды, а не только True и False.

## Принадлежность и идентичность
```python
print("кот" in "котёнок")       # True
print(4 not in [1, 2, 3])      # True
value = None
print(value is None)           # True
```
in проверяет наличие. is проверяет, один ли это объект в памяти. Для обычного сравнения чисел и строк нужен ==. Проверку отсутствующего значения принято писать is None.

## Применение формул
```python
base = 20
height = 10
triangle_area = 0.5 * base * height
radius = 10
circle_area = 3.141592653589793 * radius ** 2
print(triangle_area)
print(circle_area)
```
Дробные числа хранятся с ограниченной точностью: 0.1 + 0.2 может выглядеть как 0.30000000000000004. Для проверки близости используют math.isclose, а для денежных расчётов — Decimal или целые копейки.

# Строки: работаем с текстом

## Создание и соединение
Строка str — последовательность символов. Её можно записать в одинарных или двойных кавычках. Тройные кавычки позволяют разместить текст на нескольких строках.
```python
first = "Анна"
last = 'Иванова'
full = first + " " + last
print(full)
print("ха" * 3)
print("Первая строка\nВторая строка")
print("Имя\tВозраст")
```
\n обозначает перенос строки, \t — табуляцию, \\ — обратную косую черту. Для кавычки внутри строки можно использовать другой вид внешних кавычек или экранирование: "Он сказал: \"Привет\"".

## Форматирование
```python
name = "Аня"
age = 25
price = 19.9
print(f"{name}, через год тебе {age + 1}")
print(f"Цена: {price:.2f} руб.")
print("{}: {}".format(name, age))
print("%s: %d" % (name, age))
```
Для нового кода обычно удобнее f-строка: перед кавычками ставится f, внутри фигурных скобок — выражения. :.2f показывает ровно два знака после точки. Старые способы встречаются в чужом коде, поэтому полезно узнавать их.

## Индексы и срезы
```python
word = "Python"
print(word[0])     # P: считаем с нуля
print(word[-1])    # n: последний символ
print(word[0:3])   # Pyt: позиции 0, 1, 2
print(word[2:])    # thon
print(word[:2])    # Py
print(word[::2])   # Pto
print(word[::-1])  # nohtyP
```
В срезе [начало:конец:шаг] конец не включается. Обращение к несуществующему индексу вызывает IndexError. Срез за пределами строки допустим. Строки неизменяемы: word[0] = "J" не сработает. Нужно создать новую строку.

## Методы строк
Метод — функция, которую вызывают через точку у конкретного объекта. Методы ниже возвращают новый результат, исходный текст не меняют.
```python
text = "  Привет, Python!  "
print(text.strip())                 # убирает пробелы с краёв
print(text.lower())                 # нижний регистр
print(text.upper())                 # верхний регистр
print(text.replace("Python", "мир"))
print("яблоко,груша".split(","))    # список частей
print(" / ".join(["Москва", "Казань"]))
print("банан".count("а"))           # 2
print("банан".find("на"))           # 2; -1, если не найдено
print("банан".index("на"))          # ValueError, если не найдено
```
split разбивает одну строку, join соединяет список строк. strip("ab") удаляет любые символы a и b с обоих краёв, а не конкретное слово ab.

## Другие полезные методы
```python
print("python".capitalize())     # Python
print("hello world".title())     # Hello World
print("PyThOn".swapcase())       # pYtHoN
print("main.py".endswith(".py"))
print("https://example.com".startswith("https://"))
print("123".isdigit())
print("abc".isalpha())
print("abc123".isalnum())
print("user_name".isidentifier())
print("abc".islower(), "ABC".isupper())
print("   ".isspace())
print("a-b-a".rfind("a"))         # последний найденный индекс
```
isdecimal, isdigit и isnumeric проверяют разные классы числовых символов Unicode; они не заменяют попытку преобразования float. expandtabs заменяет табуляции пробелами. Не пытайся запомнить всё за вечер.

# Списки: несколько значений вместе

## Создание и чтение
Список list — упорядоченная изменяемая коллекция. Представь список покупок: можно дописать продукт, удалить его или заменить. Элементы могут иметь разные типы, хотя часто удобнее хранить однотипные данные.
```python
fruits = ["яблоко", "банан", "груша"]
empty = []
print(len(fruits))
print(fruits[0])
print(fruits[-1])
print(fruits[1:])
fruits[1] = "апельсин"
```
Индексы и срезы устроены так же, как у строк. В отличие от строки, элемент списка можно заменить. Индекс вне диапазона вызовет IndexError.

## Добавление и удаление
```python
items = ["хлеб", "молоко"]
items.append("чай")             # один элемент в конец
items.insert(1, "сыр")          # вставить перед индексом 1
items.extend(["рис", "соль"])   # добавить элементы коллекции
items.remove("молоко")          # удалить первое совпадение
last = items.pop()              # удалить и вернуть последний
del items[0]                    # удалить по индексу
print(items, last)
```
remove вызовет ValueError, если значения нет. pop на пустом списке вызовет IndexError. clear очищает весь список. append([1, 2]) добавит один вложенный список, extend([1, 2]) добавит два отдельных числа.

## Поиск, порядок и сортировка
```python
numbers = [3, 1, 2, 1]
print(2 in numbers)
print(numbers.count(1))  # 2
print(numbers.index(2))  # 2
print(sorted(numbers))  # новый отсортированный список
print(numbers)          # старый порядок
numbers.sort()          # меняет сам список
numbers.reverse()       # разворачивает текущий порядок
print(numbers)
```
sort и reverse возвращают None. Ошибка новичка: numbers = numbers.sort(). После этого numbers больше не список, а None. Для убывания используй sort(reverse=True). Сравнивать числа со строками при сортировке нельзя без явного правила key.

## Копирование — важная ловушка
```python
a = [1, 2]
b = a
b.append(3)
print(a)          # [1, 2, 3]: это тот же список
c = a.copy()
c.append(4)
print(a)          # [1, 2, 3]: копия отдельно
```
Присваивание не создаёт копию объекта. copy и срез [:] создают поверхностную копию: вложенные списки внутри по-прежнему общие. Для полной независимости вложенных структур есть copy.deepcopy.

## Распаковка и объединение
```python
first, second, *rest = [10, 20, 30, 40]
print(first, second, rest)
print([1, 2] + [3, 4])
print([0] * 3)
matrix = [[1, 2], [3, 4]]
print(matrix[1][0])  # 3
```
Не создавай таблицу как [[0] * 3] * 3, если будешь менять строки: все строки окажутся одним объектом. Позже научимся делать независимые строки через генератор списка.

# Кортежи: последовательность без изменений

## Чем кортеж отличается от списка
Кортеж tuple — упорядоченная коллекция, элементы которой нельзя заменить после создания. Он подходит для координат, даты или фиксированного набора полей. Список удобен там, где набор нужно менять.
```python
point = (10, 20)
print(point[0])
print(point[-1])
print(len(point))
print(point[:1])
empty = ()
single = (42,)  # запятая обязательна!
print(type(single))
```
(42) — просто число в скобках. Кортеж создаёт именно запятая. Можно написать point = 10, 20, но скобки часто лучше читаются.

## Методы и преобразования
```python
values = (1, 2, 2, 3)
print(values.count(2))  # 2
print(values.index(3))  # 3
print(2 in values)
print(values + (4, 5))
editable = list(values)
editable.append(4)
new_values = tuple(editable)
print(new_values)
```
У кортежа нет append, remove или sort. Чтобы получить изменённую последовательность, создают новый кортеж. del values удаляет имя переменной, а не отдельный элемент кортежа.

## Распаковка
```python
person = ("Аня", 25, "Казань")
name, age, city = person
print(name, age, city)
first, *middle, last = (1, 2, 3, 4)
print(first, middle, last)
```
Число переменных должно совпадать с числом элементов, если нет звёздочки. Переменная со звёздочкой получает список оставшихся элементов.

## Тонкость неизменяемости
```python
record = ("покупки", ["хлеб"])
record[1].append("сыр")
print(record)
```
Кортеж запрещает замену своих ссылок на элементы. Но изменяемый список внутри кортежа может меняться. Это пригодится, когда будешь разбираться с вложенными данными.

# Множества: только уникальные значения

## Зачем нужно множество
Множество set хранит уникальные элементы и удобно для проверки принадлежности. Повторения исчезают. На порядок вывода полагаться нельзя: у множества нет индексов и срезов.
```python
tags = {"Python", "учёба", "Python"}
print(len(tags))  # 2
print("Python" in tags)
empty = set()    # {} создаёт словарь!
numbers = set([1, 1, 2, 3])
print(sorted(numbers))  # для предсказуемого вывода
```
Элементы множества должны быть хешируемыми: подходят строки, числа, многие кортежи. Список или словарь добавить нельзя, потому что они изменяемы и не хешируются.

## Изменение
```python
skills = {"Python"}
skills.add("SQL")
skills.update(["Git", "SQL"])
skills.remove("Git")       # ошибка, если элемента нет
skills.discard("Java")     # без ошибки, если нет
print(sorted(skills))
```
pop удаляет произвольный элемент и возвращает его; на пустом множестве вызывает KeyError. clear очищает множество. del удаляет имя.

## Операции как на кругах Эйлера
```python
a = {1, 2, 3}
b = {3, 4}
print(sorted(a | b))  # объединение: 1, 2, 3, 4
print(sorted(a & b))  # пересечение: 3
print(sorted(a - b))  # только в a: 1, 2
print(sorted(a ^ b))  # только в одном из двух: 1, 2, 4
```
Те же действия доступны как union, intersection, difference и symmetric_difference. Методы intersection_update и difference_update меняют исходное множество. Обычные intersection и difference создают новое.

## Подмножество и непересекающиеся наборы
```python
print({1, 2}.issubset({1, 2, 3}))    # True
print({1, 2, 3}.issuperset({1, 2}))  # True
print({1, 2}.isdisjoint({3, 4}))    # True: нет общих
print({1, 2} <= {1, 2, 3})          # подмножество
```
Строгое подмножество обозначается < и не может быть равно исходному набору. Неизменяемый вариант множества — frozenset.

## Практика
1. Из списка возрастов убери повторы и сравни длины списка и множества.
2. Найди общих друзей двух людей через пересечение.
3. Найди навыки, которые есть у первого человека, но нет у второго.

# Словари: значения с подписями

## Ключ и значение
Словарь dict хранит пары «ключ → значение». В списке к данным обращаются по номеру, в словаре — по осмысленному ключу. Ключи уникальны и должны быть хешируемыми; значения могут быть любыми.
```python
person = {"name": "Аня", "age": 25, "skills": ["Python"]}
print(person["name"])
print(person.get("city", "Город не указан"))
person["city"] = "Казань"
person["age"] = 26
person["skills"].append("SQL")
print(person)
```
Обращение person["missing"] вызовет KeyError. get вернёт None или указанный запасной результат. В Python 3.7+ словарь сохраняет порядок добавления, но обычная проверка равенства словарей от порядка не зависит.

## Проверки и просмотр
```python
prices = {"хлеб": 50, "чай": 120}
print("хлеб" in prices)           # ищет среди ключей
print(list(prices.keys()))
print(list(prices.values()))
print(list(prices.items()))       # пары (ключ, значение)
print(len(prices))
```
keys, values и items возвращают представления содержимого. list превращает их в обычные списки. Для поиска по значениям используй value in prices.values().

## Удаление и объединение
```python
data = {"a": 1, "b": 2}
removed = data.pop("a")
data.update({"b": 20, "c": 3})
copy = data.copy()
del data["c"]
print(data, copy, removed)
```
pop без запасного значения выдаст KeyError, если ключа нет. popitem удаляет последнюю добавленную пару. clear очищает словарь. copy создаёт поверхностную копию: вложенные списки остаются общими.

## Вложенные данные
```python
student = {
    "name": "Илья",
    "address": {"city": "Пермь"},
    "grades": [4, 5, 5],
}
print(student["address"]["city"])
print(sum(student["grades"]) / len(student["grades"]))
```
Читай такие обращения по шагам: сначала достали address из student, затем city из полученного словаря.

# Условия: программа выбирает действие

## if, elif, else
Условие позволяет выполнить блок только при определённом результате проверки. После условия ставится двоеточие. Блок сдвигается вправо на четыре пробела.
```python
age = 17
if age >= 18:
    print("Можно получить взрослый билет")
else:
    print("Нужен детский билет")
```
Отступы — часть синтаксиса, а не украшение. Все строки одного блока должны иметь одинаковый отступ. В редакторе этой книги Tab вставляет четыре пробела.

## Несколько вариантов
```python
temperature = 12
if temperature < 0:
    print("Мороз")
elif temperature < 15:
    print("Прохладно")
else:
    print("Тепло")
```
Проверки идут сверху вниз. Выполняется только первая подходящая ветка. Вторая проверка уже подразумевает, что первая оказалась ложной. Если написать несколько отдельных if, могут выполниться несколько блоков.

## Сложные условия
```python
age = 22
has_ticket = True
if age >= 18 and has_ticket:
    print("Проходи")
elif age < 18:
    print("Пока рано")
else:
    print("Нужно купить билет")
```
Условия можно вкладывать друг в друга, но несколько уровней вложенности быстро мешают чтению. Часто понятнее объединить проверки через and или or.

## Короткая запись и пустые значения
```python
score = 75
result = "зачёт" if score >= 60 else "попробуй ещё"
print(result)
name = ""
if not name:
    print("Имя пока не заполнено")
```
Короткая запись удобна для выбора одного значения. Длинные действия лучше записывать обычным блоком if. Пустая строка, пустые коллекции, 0 и None ложны в условиях.

## Практика
1. По возрасту выведи, можно ли водить автомобиль при пороге 18 лет.
2. Сравни два числа и учти равенство.
3. По оценке от 0 до 100 назначь результат: 90+ отлично, 70+ хорошо, 60+ удовлетворительно, иначе нужна практика. Отдельно проверь неверные значения.
4. Добавь фрукт в список, только если его там ещё нет.

# Циклы: повторяем без копирования кода

## for перебирает элементы
```python
for fruit in ["яблоко", "груша", "банан"]:
    print(fruit)
```
На каждом шаге очередной элемент попадает в переменную fruit. Затем выполняется блок с отступом. Имя переменной выбираешь ты.

## range и подсчёт
```python
for number in range(1, 6):
    print(number)
total = 0
for number in range(1, 101):
    total += number
print(total)  # 5050
```
range(5) даёт 0, 1, 2, 3, 4. range(1, 6) — числа от 1 до 5. Правая граница не включается. Третий аргумент задаёт шаг: range(10, 0, -2) даёт 10, 8, 6, 4, 2. Нулевой шаг запрещён.

## while повторяет, пока условие истинно
```python
count = 3
while count > 0:
    print(count)
    count -= 1
print("Старт!")
```
Не забудь менять значение, от которого зависит условие, иначе получится бесконечный цикл. Здесь запуск автоматически останавливается через несколько секунд; кнопка «Стоп» тоже завершает процесс.

## break, continue и else
```python
for number in range(1, 10):
    if number == 3:
        continue      # пропустить остаток этого шага
    if number == 6:
        break         # закончить весь цикл
    print(number)
```
else после цикла выполняется, если цикл закончился без break. Это удобно при поиске.
```python
for number in [1, 3, 5]:
    if number % 2 == 0:
        print("Нашли чётное")
        break
else:
    print("Чётных нет")
```
pass — пустая инструкция-заглушка. Она не пропускает шаг и не завершает цикл.

## Индексы, пары и вложенные циклы
```python
for index, name in enumerate(["Аня", "Илья"], start=1):
    print(index, name)
for key, value in {"чай": 120, "хлеб": 50}.items():
    print(key, value)
for row in range(2):
    for column in range(3):
        print(row, column)
```
enumerate даёт номер и элемент. Цикл по словарю без items перебирает ключи. Во вложенном цикле внутренний полностью отрабатывает для каждого шага внешнего. Не удаляй элементы списка во время прямого перебора: перебирай копию или собирай новый список.

## Практика
1. Выведи числа от 0 до 10 через for и через while.
2. Нарисуй треугольник из семи строк символов #.
3. Посчитай отдельно суммы чётных и нечётных чисел от 0 до 100.
4. Найди первое число больше 10 в списке и остановись.

# Функции: даём имя действию

## Зачем выносить код в функцию
Если одно действие повторяется, запиши его один раз и вызывай по имени. Функция помогает разбить большую задачу на маленькие понятные части.
```python
def greet(name):
    return f"Привет, {name}!"

message = greet("Аня")
print(message)
```
def начинает определение. name — параметр: место для будущего значения. "Аня" — аргумент: конкретное значение при вызове. После двоеточия идёт блок с отступом. Пока функцию не вызвали, её тело не выполняется.

## return и print — разные вещи
```python
def add(a, b):
    return a + b

result = add(2, 3)
print(result * 10)  # 50
```
return отдаёт результат вызывающему коду и завершает функцию. print лишь показывает текст на экране. Если return отсутствует, функция возвращает None. Чтобы использовать результат дальше в расчётах, его нужно вернуть.

## Аргументы по позиции и имени
```python
def introduce(name, city="Казань"):
    return f"{name}, город {city}"

print(introduce("Аня"))
print(introduce(city="Пермь", name="Илья"))
```
Значение по умолчанию используется, когда аргумент не передан. Обычные обязательные параметры идут перед параметрами с умолчанием. Именованные аргументы делают вызов понятнее.

## Несколько результатов и любое число аргументов
```python
def bounds(numbers):
    return min(numbers), max(numbers)

low, high = bounds([4, 2, 9])
print(low, high)

def total(*numbers):
    return sum(numbers)

def describe(**fields):
    return fields

print(total(1, 2, 3))
print(describe(name="Аня", age=25))
```
Несколько возвращаемых значений упаковываются в кортеж. *numbers собирает позиционные аргументы в кортеж, **fields — именованные в словарь. При вызове *list распаковывает список в аргументы, **dict — словарь в именованные аргументы.

## Область видимости
```python
rate = 10
def calculate(hours):
    pay = hours * rate
    return pay

print(calculate(3))
```
pay — локальная переменная: существует внутри вызова. rate читается из внешней области. Предпочитай передавать нужные данные параметрами и возвращать результат. Изменение глобального состояния через global делает код сложнее для понимания.

## Не используй изменяемое значение по умолчанию
Вместо def add_item(item, items=[]) пиши так:
```python
def add_item(item, items=None):
    if items is None:
        items = []
    items.append(item)
    return items

print(add_item("чай"))
print(add_item("хлеб"))
```
Значения по умолчанию создаются при определении функции, а не при каждом вызове. Один список по умолчанию неожиданно накапливал бы элементы между вызовами.

# Модули: используем готовые инструменты

## Что такое модуль
Модуль — файл с кодом Python. Через import можно получить доступ к его функциям, классам и значениям. В стандартной библиотеке много готовых инструментов: их не нужно устанавливать.
```python
import math
print(math.sqrt(81))
print(math.pi)
print(math.ceil(2.1))
print(math.floor(2.9))
print(math.log(100, 10))
```
math.sqrt — функция sqrt из модуля math. Точка указывает, где искать имя. Название своего файла math.py затенит стандартный модуль: выбирай собственные имена вроде geometry.py.

## Разные способы импорта
```python
from math import sqrt, pi
import statistics as stats
print(sqrt(16), pi)
print(stats.mean([2, 4, 6]))
```
as задаёт короткое имя. from module import * затрудняет понимание происхождения имён; для учебного и рабочего кода лучше явные импорты.

## Свой модуль
Сохрани отдельно файл helpers.py:
```python
def full_name(first, last):

```
В той же папке создай main.py:
```python
from helpers import full_name
print(full_name("Анна", "Иванова"))
```
Эти два блока — разные файлы, а не один пример. Встроенный редактор запускает один файл за раз в папке практики; для примера с несколькими файлами сохрани helpers.py в папке практики, доступной из меню программы. Код верхнего уровня модуля выполняется при первом импорте. Для запуска только при непосредственном старте файла используют if __name__ == "__main__":.

## Случайные значения и строки
```python
import random
import string
print(random.randint(1, 6))
print(random.choice(["чай", "кофе"]))
print(string.ascii_letters)

```
randint включает обе границы. random.random даёт дробь от 0 включительно до 1 не включительно. random полезен для игр, но для паролей и токенов нужен модуль secrets.

## Система и аргументы запуска

```python
import sys
from pathlib import Path
print(sys.version.split()[0])
print(Path.cwd())
print(sys.argv)
```
sys.argv содержит имя запускаемого файла и аргументы командной строки. os предоставляет работу с операционной системой: os.getcwd, os.listdir и os.makedirs. Для путей часто удобнее pathlib. Не запускай удаление папок, не понимая точный путь.

# Генераторы списков и lambda

## Сначала обычный цикл
```python
squares = []
for number in range(1, 6):
    squares.append(number ** 2)
print(squares)
```
Теперь тот же смысл короче:
```python
squares = [number ** 2 for number in range(1, 6)]
print(squares)
```
Такая конструкция называется list comprehension, или списковое включение. В обиходе — генератор списка. Читай: «возьми квадрат number для каждого number из диапазона».

## Фильтрация и выбор
```python
evens = [n for n in range(10) if n % 2 == 0]
labels = ["чётное" if n % 2 == 0 else "нечётное" for n in range(4)]
print(evens)
print(labels)
```
if после for отбирает элементы. Выражение if ... else перед for выбирает значение для каждого элемента и ничего не отбрасывает.

## Вложенные последовательности
```python
rows = [[1, 2], [3, 4], [5, 6]]
flat = [value for row in rows for value in row]
matrix = [[0 for column in range(3)] for row in range(2)]
matrix[0][0] = 9
print(flat)
print(matrix)
```
Порядок for такой же, как во вложенных циклах. Слишком длинную конструкцию лучше заменить обычными циклами. Понятность важнее краткости.

## Словари, множества и генераторные выражения
```python
lengths = {word: len(word) for word in ["кот", "собака"]}
unique_lengths = {len(word) for word in ["кот", "дом", "собака"]}
total = sum(n * n for n in range(100))
print(lengths, sorted(unique_lengths), total)
```
Круглые скобки создают генераторное выражение: элементы вычисляются по мере запроса, весь список сразу не хранится. Генератор обычно можно перебрать только один раз.

## lambda — короткая функция
```python
double = lambda x: x * 2
print(double(5))
people = [("Аня", 25), ("Илья", 19)]
print(sorted(people, key=lambda person: person[1]))
```
lambda принимает параметры и возвращает одно выражение. Для именованной функции с понятным назначением чаще лучше def. lambda полезна как короткое правило сортировки или обработки.

## Практика

# Функции, которые работают с функциями

## Функция тоже значение
Функцию можно сохранить в переменную, передать другой функции и вернуть как результат. Функцию, которая принимает или возвращает функции, называют функцией высшего порядка.
```python
def double(x):
    return x * 2

def apply(function, value):
    return function(value)

operation = double
print(apply(operation, 5))
```
double без скобок — сама функция. double(5) — её вызов и результат. Это различие важно для сортировки, обработчиков кнопок и других событий.

## map, filter, reduce
```python
from functools import reduce
numbers = [1, 2, 3, 4]
print(list(map(lambda x: x * 2, numbers)))
print(list(filter(lambda x: x % 2 == 0, numbers)))
print(reduce(lambda total, x: total + x, numbers, 0))
```
map преобразует каждый элемент. filter оставляет те, для которых правило истинно. reduce сворачивает последовательность в один результат, постепенно объединяя накопленное значение с очередным элементом. Здесь sum(numbers) был бы проще. map и filter возвращают итераторы, поэтому для печати всего результата мы превращаем их в list.

## Замыкание
```python
def make_multiplier(factor):
    def multiply(value):
        return value * factor
    return multiply

triple = make_multiplier(3)
print(triple(7))
```
Внутренняя функция помнит factor из окружения, в котором была создана. Это называется замыканием. Не нужно заучивать определение: проследи, откуда берётся число 3.

## Декоратор
Декоратор оборачивает функцию дополнительным поведением: например, пишет сообщение перед вызовом.
```python
from functools import wraps

def announce(function):
    @wraps(function)
    def wrapper(*args, **kwargs):
        print("Начинаю")
        return function(*args, **kwargs)
    return wrapper

@announce
def greet(name):
    return f"Привет, {name}"

print(greet("Аня"))
```
@announce примерно равнозначно greet = announce(greet). *args и **kwargs передают произвольные аргументы дальше. wraps сохраняет имя и документацию исходной функции. Несколько декораторов применяются снизу вверх.

## Практика
1. Преврати список строк с числами в числа через map(int, ...).
2. Отбери города, названия которых длиннее пяти букв.
3. Найди сумму списка обычным циклом, sum и reduce.
4. Напиши функцию, возвращающую функцию прибавления заданного числа.
5. Добавь декоратор, печатающий «Готово» после успешного вызова функции.

# Ошибки Python: читаем сообщения без паники

## Как читать traceback
Если программа остановилась, читай последнюю строку сообщения: там тип ошибки и причина. Выше указаны файл, номер строки и путь вызовов. Найди ближайшую строку своего кода, затем проверь значения переменных перед ней.

## Частые ошибки
- SyntaxError — Python не смог разобрать запись: пропущены скобка, кавычка или двоеточие.
- IndentationError — неверные отступы.
- NameError — имя ещё не определено или написано с ошибкой.
- IndexError — нет такого индекса в последовательности.
- KeyError — нет такого ключа в словаре.
- TypeError — действие не подходит к типу или переданы неверные аргументы.
- ValueError — тип подходящий, но значение недопустимо.
- AttributeError — у объекта нет такого метода или свойства.
- ModuleNotFoundError — не найден импортируемый модуль.
- ImportError — модуль найден, но нужный объект импортировать не удалось.
- ZeroDivisionError — деление на ноль.
- FileNotFoundError — не найден файл по указанному пути.

## Отличаем тип от значения
```python
age = "25"
print(int(age) + 1)
```
"25" + 1 вызвало бы TypeError: нельзя сложить строку и число. int("кот") вызвало бы ValueError: строка есть, но число в ней не записано. int("25") работает.

## Пошаговая диагностика
```python
prices = [50, 120]
index = 1
print("Список:", prices)
print("Индекс:", index, "Длина:", len(prices))
print(prices[index])
```
Если index был бы 2, произошло бы обращение к третьему элементу, которого нет. Последний допустимый положительный индекс равен len(prices) - 1.

## Отладка — проверка гипотез
1. Прочитай точное сообщение.
2. Найди строку.
3. Выведи важные значения через print и type.
4. Уменьши пример до нескольких строк.
5. Исправь одну причину и запусти снова.

## Не все ошибки приводят к остановке
```python
width = 5
height = 3
area = width * height
assert area == 15
print(area)
```
Если случайно написать width + height, программа выполнится, но ответ будет неверным. Это логическая ошибка. assert помогает проверить ожидания при разработке; для проверки пользовательского ввода используй обычные if, потому что assert можно отключить.

## Практика
1. По очереди намеренно вызови NameError, IndexError, KeyError и ZeroDivisionError. Каждый пример запускай отдельно.
2. Исправь сложение "5" + 2 так, чтобы получить число 7.
3. Найди ошибку в формуле площади прямоугольника width + height.
4. Запиши в заметки три ошибки, которые встретились тебе, и способ исправления.

# Даты и время

## Дата, время и момент
datetime — модуль стандартной библиотеки. date хранит дату, time — время суток, datetime — дату и время вместе, timedelta — длительность.
```python
from datetime import date, datetime, timedelta, timezone
today = date.today()
now = datetime.now(timezone.utc)
print(today)
print(now.year, now.month, now.day)
print(now.hour, now.minute, now.second)
print(today + timedelta(days=7))
```
Дата зависит от часового пояса. timezone.utc создаёт явно указанный UTC. datetime.now() без аргумента вернёт местное время без информации о часовом поясе.

## Создание и разница
```python
from datetime import date
start = date(2026, 1, 1)
finish = date(2026, 1, 10)
distance = finish - start
print(distance.days)  # 9
```
Порядок аргументов date: год, месяц, день. Недопустимая дата, например 30 февраля, вызовет ValueError. Разность двух дат — timedelta. Для длительности в секундах используй total_seconds(), а не seconds: seconds не включает целые дни.

## Форматирование и разбор
```python
from datetime import datetime
moment = datetime(2026, 10, 29, 18, 30)
print(moment.strftime("%d.%m.%Y %H:%M"))
parsed = datetime.strptime("29.10.2026", "%d.%m.%Y")
print(parsed.date())
print(moment.isoformat())
```
strftime превращает дату в текст, strptime разбирает текст по шаблону. %Y — четырёхзначный год, %m — месяц, %d — день, %H — часы, %M — минуты, %S — секунды. %A и %B дают названия дня недели и месяца и зависят от локали системы.

## Временные метки
```python
from datetime import datetime, timezone
moment = datetime(2026, 1, 1, tzinfo=timezone.utc)
stamp = moment.timestamp()
print(stamp)
print(datetime.fromtimestamp(stamp, timezone.utc))
```
Timestamp — число секунд от начала эпохи Unix. Для замера скорости кода лучше time.perf_counter, а не календарное время: системные часы могут корректироваться.

## Практика

# Обработка исключений и распаковка

## Когда ошибку можно обработать
Пользователь может ввести текст вместо числа, файл может отсутствовать. Это ожидаемые ситуации, которые программа должна объяснить. try запускает код, except обрабатывает конкретную ошибку.
```python
text = "не число"
try:
    number = int(text)
except ValueError:
    print("Введите целое число")
else:
    print(number * 2)
finally:
    print("Попытка закончена")
```
else выполняется, если блок try завершился без исключения. finally выполняется при выходе из try независимо от успеха; это место для освобождения ресурсов. Для файлов проще и надёжнее with, который изучим в главе 19.

## Лови то, что понимаешь
```python
try:
    result = 10 / 0
except ZeroDivisionError as error:
    print("На ноль делить нельзя:", error)
```
Не оборачивай всю программу в except: pass. Так можно скрыть собственную ошибку. В except (ValueError, TypeError): можно перечислить несколько ожидаемых исключений. Размещай в try небольшой участок, чтобы было ясно, какое действие обрабатывается.

## Поднимаем исключение сами
```python
def average(numbers):
    if not numbers:
        raise ValueError("Нужен хотя бы один элемент")
    return sum(numbers) / len(numbers)

print(average([4, 6]))
```
raise сообщает вызывающему коду, что операция невозможна. Часто понятнее явно отказать, чем вернуть неожиданное значение вроде 0, которое можно принять за настоящий результат.

## Распаковка коллекций
```python
first, second, *rest = [1, 2, 3, 4]
print(first, second, rest)
numbers = [3, 1, 5]
print(max(*numbers))
a = [1, 2]
b = [3, 4]
print([*a, *b])
print({**{"name": "Аня"}, **{"age": 25}})
```
Звёздочка в присваивании собирает остаток, в вызове распаковывает аргументы. При объединении словарей более позднее значение одинакового ключа заменяет раннее.

## enumerate и zip
```python
names = ["Аня", "Илья"]
ages = [25, 19]
for number, (name, age) in enumerate(zip(names, ages), start=1):
    print(number, name, age)
```
zip объединяет элементы по позиции и обычно заканчивается на самой короткой коллекции. Если длины обязаны совпадать, в Python 3.10+ можно использовать zip(..., strict=True): несовпадение вызовет ValueError.

## Практика
1. Обработай ввод "abc" вместо возраста и покажи понятное сообщение.
2. Напиши функцию деления с обработкой нулевого делителя.
3. Соедини имена и оценки через zip.
4. Создай функцию, которая отклоняет отрицательный возраст через ValueError.

# Регулярные выражения: ищем текст по шаблону

## Когда они нужны
Если нужен поиск буквального слова, достаточно in, find или replace. Регулярные выражения полезны, когда ищем структуру: последовательность цифр, повторение, несколько вариантов написания.
```python
import re
text = "Заказ 15: 3 книги за 1200 рублей"
print(re.findall(r"\d+", text))
```
r перед кавычками создаёт сырую строку: обратные косые черты передаются регулярному выражению без дополнительного экранирования Python.

## Основные операции
```python
import re
text = "Python и python"
found = re.search(r"python", text, flags=re.IGNORECASE)
if found:
    print(found.group(), found.span())
print(re.match(r"Python", text).group())
print(re.fullmatch(r"\d+", "123") is not None)
print(re.findall(r"python", text, flags=re.I))
print(re.sub(r"python", "Пайтон", text, flags=re.I))
print(re.split(r"[,;]\s*", "чай, кофе; вода"))
```
search ищет в любом месте. match — только в начале. fullmatch требует совпадения всей строки. Если совпадения нет, результат — None: нельзя сразу вызывать group без проверки. findall возвращает все совпадения, sub заменяет, split разбивает.

## Словарь знаков
- . — любой символ, обычно кроме перевода строки.
- \d — цифра, \w — буква, цифра или подчёркивание, \s — пробельный символ.
- \D, \W и \S — противоположные классы.
- [abc] — один из перечисленных символов, [a-z] — диапазон.
- [^0-9] — любой символ, кроме указанных.
- * — ноль или больше повторов, + — один или больше, ? — ноль или один.
- {3} — ровно три повтора, {2,4} — от двух до четырёх.
- ^ — начало строки, $ — конец; | — выбор варианта.
- (...) — группа; \. — буквальная точка.

## Группы и жадность
```python
import re
match = re.fullmatch(r"(\d{2})\.(\d{2})\.(\d{4})", "29.10.2026")
if match:
    day, month, year = match.groups()
    print(year, month, day)
print(re.findall(r"<.*?>", "<b>текст</b>"))
```
* и + по умолчанию жадные: берут как можно больше. Добавление ? делает их нежадными. Шаблон даты проверяет форму, но не существование даты: 99.99.2026 тоже совпадёт. Проверять саму дату нужно через datetime.

## Практика
1. Из предложения достань все целые числа.
2. Замени несколько подряд идущих пробелов одним пробелом через re.sub.
3. Проверь код из ровно шести цифр через fullmatch.
4. Найди варианты Python и python без учёта регистра.
5. Не используй регулярное выражение как полноценный парсер HTML: для HTML есть отдельные библиотеки.

# Файлы, JSON и CSV

## Где живёт файл
Относительный путь считается от текущей рабочей папки. В этой программе это отдельная папка практики: её можно открыть из меню «Данные». Файлы упражнения остаются там после запуска. Чтобы примеры не зависели от внешних данных, сначала создавай небольшой файл сам.

## Чтение и запись текста
```python
from pathlib import Path
path = Path("notes.txt")
with path.open("w", encoding="utf-8") as file:
    file.write("Первая строка\nВторая строка\n")
with path.open("r", encoding="utf-8") as file:
    print(file.read())
```
with закрывает файл даже при ошибке. encoding="utf-8" нужен для предсказуемого хранения кириллицы. Режим w перезаписывает существующий файл целиком. a дописывает в конец, r читает, x создаёт только новый файл. b означает двоичный режим, например для картинок.

## Читаем по строкам
```python
from pathlib import Path
path = Path("lines.txt")
path.write_text("чай\nхлеб\n", encoding="utf-8")
with path.open(encoding="utf-8") as file:
    for line in file:
        print(line.rstrip("\n"))
```
read читает всё содержимое, readline — одну строку, readlines — список строк. Перебор файла удобен для больших текстов. strip удаляет пробелы с обоих краёв и может убрать значимые пробелы; rstrip("\n") удаляет только переводы строк.

## JSON: обмен структурированными данными
```python
import json
from pathlib import Path
person = {"name": "Аня", "age": 25, "student": True}
text = json.dumps(person, ensure_ascii=False, indent=2)
Path("person.json").write_text(text, encoding="utf-8")
loaded = json.loads(Path("person.json").read_text(encoding="utf-8"))
print(loaded["name"])
```
dumps переводит объект в JSON-строку, loads делает обратное. dump и load работают с открытым файлом. В JSON двойные кавычки, true, false и null; после разбора они становятся Python True, False и None. Не используй eval для чтения данных.

## CSV: строки таблицы
```python
import csv
with open("people.csv", "w", encoding="utf-8", newline="") as file:
    writer = csv.writer(file)
    writer.writerow(["name", "age"])
    writer.writerows([["Аня", 25], ["Илья", 19]])
with open("people.csv", encoding="utf-8", newline="") as file:
    for row in csv.DictReader(file):
        print(row["name"], int(row["age"]))
```
CSV хранит текст: числа при чтении нужно преобразовывать. Модуль csv корректно обрабатывает запятые и кавычки внутри полей; обычный split(",") этого не умеет. Для таблиц Excel формата xlsx понадобятся дополнительные библиотеки, например openpyxl.

## Удаление
Path("name.txt").unlink() удаляет файл. Сначала проверь точный путь и существование через exists. Для учебных заданий удаляй только собственные временные файлы в папке практики.

## Практика
1. Запиши три цели обучения в текстовый файл и прочитай их.
2. Посчитай число строк и слов в созданном тексте.
3. Сохрани список покупок в JSON и восстанови его.
4. Создай CSV с расходами и посчитай их сумму.

# Пакеты и pip

## Стандартная библиотека и внешние пакеты
math, json и pathlib уже входят в Python. pandas, requests, Flask и BeautifulSoup нужно установить отдельно. pip — менеджер пакетов, который скачивает и устанавливает такие библиотеки. Название при установке может отличаться от имени при import: beautifulsoup4 устанавливается, bs4 импортируется.

## Сначала виртуальное окружение
Хотя в исходном курсе окружения обсуждаются в главе 23, пользоваться ими стоит уже сейчас. Все команды этого раздела выполняются в терминале, а не в редакторе Python. Установка требует интернета.
```text
python -m venv .venv
```
На Windows после этого:
```text
.venv\Scripts\python -m pip install requests
```
На macOS и Linux:
```text
.venv/bin/python -m pip install requests
```
На macOS/Linux первую команду обычно запускают через python3. Такой способ не требует активации: мы явно выбираем Python нужного окружения. Чтобы книга использовала установленные пакеты, запусти app.py именно этим интерпретатором.

## Полезные команды pip
```text
python -m pip --version
python -m pip list
python -m pip show requests
python -m pip install requests
python -m pip uninstall requests
python -m pip freeze > requirements.txt
python -m pip install -r requirements.txt
```
Здесь python должен означать выбранный интерпретатор окружения; можно заменить его полным путём выше. freeze фиксирует установленные версии. Для нового проекта лучше устанавливать только нужное, а не копировать все пакеты из чужой системы. Обновление выполняется с --upgrade.

## HTTP-запрос с requests
Пример требует requests и доступа к сети. Сеть здесь используется только при явном запуске этого примера.
```python
import requests
try:
    response = requests.get("https://httpbin.org/json", timeout=5)
    response.raise_for_status()
    data = response.json()
    print(data)
except requests.RequestException as error:
    print("Запрос не удался:", error)
```
status_code показывает статус, text — текст ответа, json() разбирает JSON. raise_for_status сообщает об HTTP-ошибках. timeout ограничивает ожидание; без него программа может ждать слишком долго.

## Свой пакет
Папка mypackage с __init__.py и модулями внутри может служить пакетом. Например, mypackage/arithmetic.py содержит add, а from mypackage.arithmetic import add импортирует функцию. Публикация собственного пакета — отдельная тема, для первых упражнений не нужна.

3. Сохрани список зависимостей в requirements.txt.
4. Создай чистое второе окружение и установи зависимости из файла.
5. Учебное задание во вкладке практики работает без внешних пакетов; оно не проверяет установку pip автоматически.

# Классы и объекты

## Класс — описание, объект — конкретный экземпляр
Представь анкету: у каждого человека есть имя и возраст. Класс описывает, какие данные и действия связаны с человеком. Объект хранит данные одного конкретного человека.
```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def introduce(self):
        return f"Меня зовут {self.name}, мне {self.age}"

anna = Person("Аня", 25)
ilya = Person("Илья", 19)
print(anna.introduce())
print(ilya.name)
```
__init__ инициализирует новый экземпляр. self — ссылка на тот объект, с которым сейчас работает метод. При anna.introduce() Python передаёт anna как self автоматически. Атрибуты self.name и self.age принадлежат конкретному объекту.

## Значения по умолчанию и изменение состояния
```python
class Student:
    def __init__(self, name, course="Python"):
        self.name = name
        self.course = course
        self.skills = []

    def add_skill(self, skill):
        if skill not in self.skills:
            self.skills.append(skill)

student = Student("Аня")
student.add_skill("Циклы")
print(student.skills)
```
Список создаётся внутри __init__, поэтому у каждого студента свой список. Если написать skills = [] прямо в теле класса, список станет общим атрибутом класса, что часто приводит к неожиданным изменениям.

## Наследование
```python
class Person:
    def __init__(self, name):
        self.name = name

    def greet(self):
        return f"Привет, я {self.name}"

class Student(Person):
    def __init__(self, name, course):
        super().__init__(name)
        self.course = course

    def greet(self):
        return f"{super().greet()}, изучаю {self.course}"

student = Student("Аня", "Python")
print(student.greet())
print(isinstance(student, Person))
```
Student наследует поведение Person и может переопределять методы. super обращается к реализации базового класса по порядку разрешения методов. Наследование полезно для отношения «является разновидностью». Если объект просто использует другой объект, часто проще хранить его как атрибут.

## Специальные методы
__str__ задаёт понятное человеку текстовое представление объекта. __repr__ — представление для отладки. Не нужно писать класс для каждой маленькой задачи: функции и словари часто достаточно понятны.

## Практика
1. Создай класс Dog с именем и методом bark.
2. Создай BankAccount с балансом, внесением и снятием. Не разрешай отрицательные суммы и снятие больше баланса.
3. Создай класс Statistics, который хранит список чисел и умеет находить среднее, минимум и максимум.
4. Проверь, что два экземпляра не разделяют изменяемый список случайно.

# Сбор данных со страниц

## Что такое web scraping
Это извлечение нужных данных из HTML-страницы. Браузер показывает красивую страницу, а программа обычно получает её исходный HTML. Если сайт строит содержимое через JavaScript, простой HTTP-запрос может не увидеть нужные данные.

## Начнём без интернета
В Python есть встроенный HTMLParser. Он позволяет понять идею, не устанавливая ничего.
```python
from html.parser import HTMLParser

class HeadingReader(HTMLParser):
    def __init__(self):
        super().__init__()
        self.inside = False
        self.parts = []

    def handle_starttag(self, tag, attrs):
        if tag == "h1":
            self.inside = True

    def handle_endtag(self, tag):
        if tag == "h1":
            self.inside = False

    def handle_data(self, data):
        if self.inside:
            self.parts.append(data)

reader = HeadingReader()
reader.feed("<h1>Учим Python</h1><p>Начинаем</p>")
print("".join(reader.parts))
```
Это упрощённый обработчик заголовков, а не универсальный парсер всех случаев вложенной разметки.

## BeautifulSoup
В терминале выбранного окружения установи requests и beautifulsoup4. Затем можно разбирать HTML более удобным способом:
```python
from bs4 import BeautifulSoup
html = '<h1>Книга</h1><a href="/lesson/1">Первый урок</a>'
soup = BeautifulSoup(html, "html.parser")
print(soup.h1.get_text(strip=True))
for link in soup.find_all("a"):
    print(link.get_text(strip=True), link.get("href"))
```
find ищет первый элемент, find_all — все. select(".class-name") использует CSS-селекторы. get_text извлекает текст, get("href") — атрибут ссылки. Если элемент может отсутствовать, проверь результат перед вызовом методов.

## Получаем настоящую страницу
```python
import requests
from bs4 import BeautifulSoup
response = requests.get("https://example.com", timeout=5)
response.raise_for_status()
soup = BeautifulSoup(response.text, "html.parser")
title = soup.find("h1")
print(title.get_text(strip=True) if title else "Заголовка нет")
```
Сначала проверь статус ответа, потом разбирай содержимое. Относительные ссылки вроде /about можно превратить в полные через urllib.parse.urljoin. Для учебного проекта используй страницы, сбор данных с которых разрешён, и не отправляй частые запросы. Если есть готовый API, он обычно надёжнее разбора верстки.

## Практика
1. Создай HTML-строку с тремя ссылками и выведи их адреса.
2. Извлеки текст всех h2.
3. Сохрани результат в JSON.
4. Обработай отсутствие заголовка так, чтобы программа не падала.

# Виртуальные окружения

## Зачем отдельная папка с Python
Один проект может требовать одну версию библиотеки, другой — другую. Виртуальное окружение хранит отдельный набор пакетов для проекта. Исходники и документы лежат рядом, но не внутри .venv. Саму папку .venv не коммитят в Git и не пересылают как переносимую установку.

## Создание
Открой терминал в папке проекта и выполни:
```text
python -m venv .venv
```
На macOS/Linux обычно python3 -m venv .venv. На некоторых Linux-системах сначала требуется установить системный пакет python3-venv. Команды терминала не запускаются во вкладке редактора Python.

## Использование без активации
На Windows:
```text
.venv\Scripts\python -m pip install requests
.venv\Scripts\python app.py
```
На macOS/Linux:
```text
.venv/bin/python -m pip install requests
.venv/bin/python app.py
```
Это самый явный способ: видно, какой интерпретатор запускается. В этой книге дочерний процесс использует тот же Python, которым запущена книга.

## Активация как удобное сокращение
В Windows cmd:
```text
.venv\Scripts\activate.bat
```
В PowerShell:
```text
.venv\Scripts\Activate.ps1
```
В macOS/Linux:
```text
source .venv/bin/activate
```
После активации команда python ссылается на окружение. deactivate возвращает прежнее состояние. Если PowerShell запрещает запуск скриптов, можно использовать прямой путь к интерпретатору вместо изменения системной политики.

## Проверка
```python
import sys
print(sys.executable)
print(sys.prefix != sys.base_prefix)
```
True во второй строке обычно означает, что работает виртуальное окружение. Активация лишь меняет поиск команд в текущем терминале; магического глобального переключения Python не происходит.

## Зависимости проекта
```text
python -m pip freeze > requirements.txt
python -m pip install -r requirements.txt
```
Сохраняй requirements.txt вместе с кодом. Для восстановления проекта создают новое окружение и устанавливают зависимости из этого файла. Не называй окружение env.py или именем стандартного модуля.

## Практика
1. Создай окружение для книги.
2. Установи requests только в него.
3. Запусти книгу его интерпретатором и проверь sys.executable в редакторе.
4. Создай requirements.txt и запиши в заметки команды запуска для своей системы.

# Статистика и NumPy

## Что рассказывают числа
Среднее — сумма значений, делённая на их количество. Медиана — значение в середине отсортированного набора; при чётном количестве берут среднее двух центральных. Мода — наиболее частое значение. Размах — максимум минус минимум.
```python
import statistics as stats
ages = [19, 20, 20, 21, 40]
print(stats.mean(ages))        # 24
print(stats.median(ages))      # 20
print(stats.multimode(ages))   # [20]
print(max(ages) - min(ages))   # 21
```
Возраст 40 заметно сдвигает среднее, но почти не влияет на медиану. Поэтому одно среднее не всегда хорошо описывает группу. На пустом наборе среднее не определено.

## Разброс
```python
import statistics as stats
values = [2, 4, 4, 4, 5, 5, 7, 9]
print(stats.pvariance(values))  # дисперсия совокупности
print(stats.pstdev(values))     # стандартное отклонение: 2
print(stats.variance(values))   # выборочная дисперсия
```
Дисперсия показывает средний квадрат отклонения от среднего. Стандартное отклонение — квадратный корень дисперсии, выраженный в исходных единицах. pvariance делит на N, variance — на N - 1 и требует хотя бы двух значений. Выбирай определение по смыслу данных.

## NumPy: массивы вместо списков
Установи numpy в выбранное окружение через python -m pip install numpy. Следующие блоки требуют этот пакет.
```python
import numpy as np
a = np.array([1, 2, 3, 4])
print(a * 2)         # каждый элемент умножен на 2
print(a + 10)
print(a.mean(), a.min(), a.max())
print(a.shape, a.ndim, a.dtype)
print(a[a > 2])      # фильтр по булевой маске
```
Список [1, 2] * 2 повторяется, массив np.array([1, 2]) * 2 умножается поэлементно. dtype — тип элементов; shape — размеры по осям; ndim — число осей. Массив обычно хранит однотипные данные.

## Матрицы, формы и оси
```python
import numpy as np
matrix = np.arange(1, 7).reshape(2, 3)
print(matrix)
print(matrix[0, 1])
print(matrix[:, 0])
print(matrix.sum(axis=0))  # сумма по строкам, по одному итогу на столбец
print(matrix.sum(axis=1))  # сумма внутри каждой строки
print(np.zeros((2, 3)))
print(np.ones((2, 2)))
print(np.linspace(0, 1, 5))
```
reshape меняет форму при сохранении количества элементов. Массив 2×3 содержит 6 элементов, поэтому его нельзя переделать в 2×4. Срезы NumPy часто являются представлениями общих данных: для независимой копии нужен .copy().

## Вычисления и случайность
```python
import numpy as np
rng = np.random.default_rng(42)
sample = rng.normal(loc=0, scale=1, size=1000)
print(round(float(sample.mean()), 2))
print(round(float(sample.std()), 2))
print(np.sqrt(np.array([1, 4, 9])))
left = np.array([[1, 2], [3, 4]])
right = np.eye(2)
print(left @ right)
```
* для двух массивов означает поэлементное умножение, @ — матричное. Broadcast позволяет, например, прибавить одно число ко всем элементам. Формы должны быть совместимы. np.std по умолчанию использует ddof=0; для выборочного варианта часто нужен ddof=1.

## График
matplotlib — отдельный пакет. В обычном файле график можно сохранить так:
```python
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
plt.plot([1, 2, 3], [2, 4, 6])
plt.xlabel("Шаг")
plt.ylabel("Значение")
plt.savefig("chart.png")
plt.close()
print("Сохранён chart.png в папке практики")
```
Встроенный запуск не показывает отдельные графические окна; открывай сохранённый файл. Гистограмма plt.hist показывает распределение значений, scatter — пары координат. Корреляция не доказывает причинность.

2. Добавь большое выбивающееся значение и сравни среднее и медиану.

4. Сохрани гистограмму случайных чисел в PNG.

# Pandas: таблицы в Python

## Series и DataFrame
pandas — библиотека анализа табличных данных. Series похожа на столбец с подписями строк. DataFrame — целая таблица. Для примеров нужен пакет pandas: установи его в окружение, которым запускаешь книгу.
```python
import pandas as pd
table = pd.DataFrame({
    "name": ["Аня", "Илья", "Оля"],
    "age": [25, 19, 31],
    "city": ["Казань", "Пермь", "Казань"],
})
print(table)
print(table["age"])
print(table.shape)
print(table.dtypes)
```
shape — число строк и столбцов. dtypes — тип каждого столбца. Индекс строки не обязательно совпадает с её позицией.

## Осмотр данных
```python
import pandas as pd
table = pd.DataFrame({"age": [25, 19, 31], "score": [80, 90, 70]})
print(table.head())
print(table.tail(2))
print(table.describe())
table.info()
```
head и tail показывают начало и конец. describe даёт статистики числовых столбцов. info печатает структуру и число непустых значений, а возвращает None.

## Выбор и фильтрация
```python
import pandas as pd
table = pd.DataFrame({"name": ["Аня", "Илья", "Оля"], "age": [25, 19, 31]})
print(table[table["age"] >= 21])
print(table.loc[table["age"] >= 21, ["name", "age"]])
print(table.iloc[0, 1])
table["next_age"] = table["age"] + 1
table.loc[table["name"] == "Аня", "age"] = 26
print(table.sort_values("age"))
```
loc выбирает по меткам и условиям, iloc — по целочисленным позициям. Для изменения части таблицы используй loc, а не цепочку table[условие][столбец]. Несколько условий соединяются через & и |, каждое условие берётся в скобки.

## Пропуски и преобразования
```python
import pandas as pd
table = pd.DataFrame({"age": [25, None, 31], "price": ["10", "ошибка", "30"]})
print(table.isna().sum())
table["age"] = table["age"].fillna(table["age"].median())
table["price"] = pd.to_numeric(table["price"], errors="coerce")
print(table.dropna(subset=["price"]))
```
Пропуск — не ноль. Решение удалить строку или заполнить значение зависит от задачи. coerce превращает неразбираемые значения в пропуски. astype подходит, когда все значения уже совместимы с нужным типом.

## Группы и объединение
```python
import pandas as pd
orders = pd.DataFrame({"city": ["Казань", "Пермь", "Казань"], "amount": [100, 200, 50]})
print(orders.groupby("city")["amount"].sum())
print(orders["city"].value_counts())
print(pd.concat([orders, orders], ignore_index=True).shape)
```
groupby группирует строки по значению и позволяет посчитать итоги. concat склеивает таблицы, merge объединяет по ключам, как соединение таблиц в базе данных. Если ключи повторяются с обеих сторон, merge может резко увеличить количество строк.

## Файлы
```python
import pandas as pd
table = pd.DataFrame({"name": ["Аня", "Илья"], "score": [80, 90]})
table.to_csv("scores.csv", index=False, encoding="utf-8")
loaded = pd.read_csv("scores.csv", encoding="utf-8")
print(loaded)
```
index=False не сохраняет служебный индекс как лишний столбец. Для Excel потребуются дополнительные движки, например openpyxl. После чтения настоящего файла сначала проверь типы, пропуски и размер таблицы, затем считай выводы.

# Python для веба

## Браузер и сервер
Браузер отправляет HTTP-запрос по URL. Сервер выбирает обработчик и возвращает ответ: HTML, JSON, файл или сообщение об ошибке. Python часто используется на сервере. HTML описывает структуру страницы, CSS — внешний вид, JavaScript — поведение в браузере.

## Flask
Flask — небольшой веб-фреймворк. Установи его в окружении через python -m pip install Flask. Следующий пример сохрани как web_app.py и запускай отдельно в терминале: встроенный запуск книги ограничен по времени и не предназначен для постоянного сервера.
```python
from flask import Flask
app = Flask(__name__)

@app.get("/")
def home():
    return "<h1>Привет из Python!</h1>"

@app.get("/hello/<name>")
def hello(name):
    from markupsafe import escape
    return f"Привет, {escape(name)}!"

if __name__ == "__main__":
    app.run(host="127.0.0.1", port=5000)
```
Открой http://127.0.0.1:5000 в браузере. @app.get связывает адрес с функцией. <name> — переменная часть пути. escape превращает специальные символы пользовательского текста в безопасное HTML-представление. Сервер останавливается Ctrl+C в терминале.

## Шаблоны
Рядом с web_app.py создай папку templates и файл home.html внутри неё:
```html
<!doctype html>
<html lang="ru">
<meta charset="utf-8">
<title>Моя книга</title>
<h1>Привет, {{ name }}!</h1>
<ul>{% for topic in topics %}<li>{{ topic }}</li>{% endfor %}</ul>
</html>
```
Обработчик страницы может вернуть render_template("home.html", name="Аня", topics=["Списки", "Функции"]). render_template нужно импортировать из flask. Jinja подставляет переменные и по умолчанию экранирует значения в HTML-шаблонах. Общий каркас страниц можно вынести в базовый шаблон через extends и block.

## Формы и статические файлы
CSS и изображения обычно кладут в static. URL для них строят через url_for("static", filename="style.css"). HTML-форма отправляет данные через GET или POST. В Flask поля доступны через request.args для параметров URL и request.form для полей формы. Проверяй полученные значения перед расчётами и сохранением.

# MongoDB: храним данные между запусками

## База данных вместо временных переменных
После завершения программы переменные исчезают. База данных сохраняет записи и помогает искать, обновлять и удалять их. В MongoDB записи называются документами и похожи на словари. Документы объединяются в коллекции, коллекции — в базы данных. Внутренний формат BSON поддерживает больше типов, чем обычный JSON.

## Сначала модель на обычном списке
```python
students = [
    {"name": "Аня", "age": 25},
    {"name": "Илья", "age": 19},
]
adults = [person for person in students if person["age"] >= 21]
print(adults)
```
Это не база данных: изменения исчезнут после запуска. Но смысл фильтрации такой же, как у запроса. Чтобы подготовиться к реальной MongoDB, разберись с документами и условиями на этом маленьком примере.

## Подключение
Нужен отдельный сервер MongoDB: локальный или облачный Atlas, а также пакет pymongo. Он не входит в комплект книги. Строка подключения зависит от твоей установки и не должна попадать в публичный код.
```python
import os
from pymongo import MongoClient
client = MongoClient(os.environ["MONGODB_URI"], serverSelectionTimeoutMS=3000)
database = client["python_study"]
collection = database["students"]
print(client.admin.command("ping"))
client.close()
```
Задай MONGODB_URI в окружении перед запуском отдельного файла. Не вставляй пароль в репозиторий или заметки курса. Для локальной установки строка часто начинается с mongodb://localhost:27017/, но конкретные настройки нужно брать из собственной установки.

## CRUD: создать, прочитать, обновить, удалить
Следующие фрагменты предполагают, что collection уже получена из открытого подключения выше. Они изменяют выбранную коллекцию; используй отдельную учебную базу.
```python
result = collection.insert_one({"name": "Аня", "age": 25})
print(result.inserted_id)
person = collection.find_one({"_id": result.inserted_id})
print(person)
collection.update_one({"_id": result.inserted_id}, {"$set": {"age": 26}})
collection.delete_one({"_id": result.inserted_id})
```
MongoDB обычно создаёт уникальный _id типа ObjectId. insert_many добавляет несколько документов. update_many и delete_many действуют на все совпадения. Пустой фильтр {} означает все документы: особенно внимательно относись к операциям удаления.

## Фильтры, поля, сортировка и лимит
```python
query = {"age": {"$gte": 18, "$lt": 30}}
for person in collection.find(query, {"name": 1, "age": 1, "_id": 0}).sort("age", 1).limit(5):
    print(person)
```
$gte означает ≥, $gt — >, $lte — ≤, $lt — <, $in — принадлежность набору. Проекция задаёт поля ответа. sort(..., 1) сортирует по возрастанию, -1 — по убыванию. find возвращает курсор, который перебирают. Для часто используемых поисковых полей создают индексы, но они требуют дополнительного места и времени при записи.

## Практика
1. На списке словарей реализуй добавление, поиск по имени и изменение возраста.
2. При наличии MongoDB повтори действия в отдельной учебной коллекции.
3. Добавь фильтр по диапазону возраста и сортировку.
4. До удаления выведи выбранные записи и убедись, что фильтр правильный.

# API: программы общаются с программами

## Что такое API
API — договор о способах обращения к программе. HTTP API определяет адреса, методы, формат запросов и ответов. Если сайт — интерфейс для человека, то API часто служит интерфейсом для другой программы.

Представь сервис книг. GET /books получает список, GET /books/7 — одну книгу, POST /books создаёт новую, PATCH /books/7 меняет часть полей, DELETE /books/7 удаляет запись. PUT обычно заменяет представление ресурса целиком. Это распространённые соглашения, а точные правила задаёт документация конкретного API.

## Статусы HTTP
- 200 OK — запрос выполнен.
- 201 Created — создан новый ресурс.
- 204 No Content — успешно, тела ответа нет.
- 400 Bad Request — запрос некорректен.
- 401 Unauthorized — нужна действительная аутентификация.
- 403 Forbidden — доступ запрещён.
- 404 Not Found — ресурс не найден.
- 429 Too Many Requests — слишком много запросов.
- 500 Internal Server Error — ошибка сервера.

## JSON и проверка данных
```python
import json
response_text = '{"books": [{"id": 1, "title": "Python"}]}'
data = json.loads(response_text)
for book in data["books"]:
    print(book["id"], book["title"])
```
Успешный HTTP-ответ ещё не гарантирует нужную структуру данных. Проверяй типы и обязательные поля. Не все ответы являются JSON: иногда сервер присылает HTML-страницу ошибки.

## Запрос из Python
При установленном requests и доступе к сети:
```python
import requests
response = requests.get(
    "https://httpbin.org/get",
    params={"topic": "python", "page": 1},
    timeout=5,
)
response.raise_for_status()
data = response.json()
print(data["args"])
```
params формирует параметры URL. Для POST с JSON используют json={...}. Заголовки передаются через headers={...}. API-ключи берут из переменных окружения, а не вписывают в публичный файл. Для учебного примера httpbin ключ не нужен.

## Пагинация и ограничения
Большие списки обычно возвращают частями: страницами или курсорами. Пока документация не говорит об окончании, нужно запрашивать следующую часть. Не угадывай формат курсора. При 429 учитывай Retry-After. Повторение POST без защиты от дубликатов может создать несколько записей.

## Практика
1. Придумай адреса и методы API для списка задач.
2. Разбери JSON с книгами и выведи только названия.
3. Обработай отсутствие ожидаемого поля.
4. Запиши, чем отличаются 400, 401, 403 и 404.

# Создаём своё API

## Минимальный сервис задач
Установи Flask в виртуальное окружение. Сохрани следующий код в отдельный файл api_app.py и запусти в терминале через python api_app.py. В книге длительные серверы автоматически останавливаются, поэтому этот пример запускается отдельно.
```python
from flask import Flask, jsonify, request

app = Flask(__name__)
tasks = {}
next_id = 1

@app.get("/tasks")
def list_tasks():
    return jsonify(list(tasks.values()))

@app.get("/tasks/<int:task_id>")
def get_task(task_id):
    task = tasks.get(task_id)
    if task is None:
        return jsonify(error="Задача не найдена"), 404
    return jsonify(task)

@app.post("/tasks")
def create_task():
    global next_id
    data = request.get_json(silent=True)
    if not isinstance(data, dict):
        return jsonify(error="Нужен JSON-объект"), 400
    title = data.get("title")
    if not isinstance(title, str) or not title.strip():
        return jsonify(error="Нужно непустое текстовое title"), 400
    task = {"id": next_id, "title": title.strip(), "done": False}
    tasks[next_id] = task
    next_id += 1
    return jsonify(task), 201

@app.patch("/tasks/<int:task_id>")
def update_task(task_id):
    if task_id not in tasks:
        return jsonify(error="Задача не найдена"), 404
    data = request.get_json(silent=True)
    if not isinstance(data, dict) or not isinstance(data.get("done"), bool):
        return jsonify(error="Нужно логическое поле done"), 400
    tasks[task_id]["done"] = data["done"]
    return jsonify(tasks[task_id])

@app.delete("/tasks/<int:task_id>")
def delete_task(task_id):
    if task_id not in tasks:
        return jsonify(error="Задача не найдена"), 404
    del tasks[task_id]
    return "", 204

if __name__ == "__main__":
    app.run(host="127.0.0.1", port=5000)
```
Пример хранит данные в памяти одного процесса. При перезапуске они исчезнут. Он предназначен для локального изучения, не для общей базы в многопроцессном сервере. Позже tasks можно заменить коллекцией MongoDB или таблицей SQLite.

## Как проверить
Браузер умеет открыть GET http://127.0.0.1:5000/tasks. Для POST и PATCH удобен отдельный клиент на Python:
```python
import requests
base = "http://127.0.0.1:5000"
created = requests.post(base + "/tasks", json={"title": "Пройти главу"}, timeout=3)
created.raise_for_status()
task = created.json()
print(task)
updated = requests.patch(base + f"/tasks/{task['id']}", json={"done": True}, timeout=3)
print(updated.status_code, updated.json())
```
Клиент запускается после старта сервера. Проверяй не только успешный путь: отправь пустое название, число вместо текста, неизвестный id, неверный тип done. Хороший API объясняет ошибку и возвращает соответствующий статус.

## Следующие шаги
Добавь постоянное хранение, разделение обработчиков и данных, проверку входных полей и тесты. Если приложение когда-нибудь выйдет за пределы компьютера, потребуются аутентификация и подходящий сервер размещения. Не включай debug для публичного сервера.

## Практика
1. Запусти API и создай две задачи.
2. Отметь одну выполненной и удали вторую.
3. Проверь ответы для отсутствующего id и пустого title.
4. Добавь фильтр /tasks?done=true. Явно разбери текстовый параметр, потому что bool("false") даёт True.

## Проект: личный список задач
Сделай консольную программу, которая позволяет добавить задачу, показать список, отметить задачу выполненной и удалить её. Данные должны сохраняться в tasks.json. Библиотек сверх стандартной не нужно.

Начни с модели данных:
```python
tasks = [
    {"id": 1, "title": "Повторить функции", "done": False},
    {"id": 2, "title": "Решить три задачи", "done": True},
]
for task in tasks:
    mark = "✓" if task["done"] else "○"
    print(f"{mark} {task['id']}. {task['title']}")
```
Затем добавь функции add_task, complete_task, delete_task, load_tasks и save_tasks. Каждая должна заниматься одним понятным действием. Для нового id используй max существующих id плюс 1, а не просто длину списка: после удаления длина может совпасть со старым id.

## Делай по одному шагу
1. Покажи заранее записанный список.
2. Добавь новую задачу в память.
3. Реализуй поиск по id и отметку done.
4. Сохрани в JSON через json и pathlib.
5. Загрузи из файла при запуске. При отсутствии файла начни с пустого списка; повреждённый файл не перезаписывай молча.
6. Добавь меню while, которое заканчивается по команде выхода.
7. Проверь неправильные команды, пустое название и неизвестный id.

Для интерактивного меню удобнее отдельный терминал: встроенная практика получает заранее подготовленный ввод и ограничивает время выполнения. Сохрани свой код через кнопку «Сохранить .py» и запусти его самостоятельно.

## Как оценить готовность
Программа не теряет данные после перезапуска. После удаления и добавления id не повторяются. Ошибочный ввод не завершает работу неожиданно. Есть README с командой запуска и примером использования. Ты можешь объяснить каждую функцию собственными словами.
