Первые шаги: ты уже можешь писать программы

Что мы будем делать

Python — язык, на котором человек записывает инструкции для компьютера. Программа — обычный текст с такими инструкциями. Интерпретатор Python читает этот текст и выполняет его сверху вниз. Ты будешь учиться маленькими шагами: прочитал, запустил пример, изменил его, решил задачу.

30 дней — название исходного курса, а не срок сдачи. На одну главу можно потратить несколько вечеров. Если застрял, вернись к примеру и поменяй только одну строчку.

Эта книга — русская учебная адаптация 30 Days Of Python Асабенеха Йетайеха с дополнительными объяснениями. Она охватывает все 30 тем, но не является дословным переводом всех упражнений и материалов оригинала. Английские главы сохранены отдельно в папке original.

Слева — оглавление. Во вкладке «Урок» читаешь объяснения. Во вкладке «Практика» редактируешь и запускаешь настоящий Python. «Заметки» — твой блокнот. Код, заметки и отметки о прохождении сохраняются на этом компьютере автоматически. Кнопка «Завершить главу» — твоя собственная отметка, она не означает сдачу экзамена.

Первая инструкция

print("Привет, мир!")
print(2 + 3)

print — встроенная функция: готовая команда для вывода на экран. В круглых скобках пишут, что вывести. Текст заключают в кавычки, числа — нет. Первая строка напечатает Привет, мир!, вторая — 5. Каждая инструкция здесь записана на своей строке.

Слова print, if, for остаются английскими: это часть языка. Их не переводят в самом коде. В тексте и комментариях можно писать по-русски.

Python как калькулятор

print(3 + 2)    # сложение: 5
print(3 - 2)    # вычитание: 1
print(3 * 2)    # умножение: 6
print(3 / 2)    # деление: 1.5
print(3 ** 2)   # степень: 9
print(3 % 2)    # остаток: 1
print(3 // 2)   # деление с округлением вниз: 1

Знак # начинает комментарий. Python пропускает всё после него до конца строки. Комментарий нужен человеку, чтобы объяснить смысл кода.

Какие бывают данные

print(type(10))          # int: целое число
print(type(3.14))        # float: дробное число
print(type(2 + 3j))      # complex: комплексное число
print(type("Привет"))    # str: строка, то есть текст
print(type(True))        # bool: истина или ложь
print(type([1, 2, 3]))   # list: список
print(type((1, 2)))      # tuple: кортеж
print(type({1, 2}))      # set: множество
print(type({"имя": "Аня"}))  # dict: словарь

type показывает тип значения. Пока достаточно отличать число от текста. "10" — текст из двух символов; 10 — число, с которым можно считать.

Переменные и встроенные функции

Переменная — имя для значения

Представь подписанную коробку. Надпись age помогает найти нужное значение. В Python переменная — имя, связанное с объектом. Значение вычисляется справа от знака =, а имя записывается слева.

name = "Аня"
age = 25
height = 1.68
is_student = True
print(name)
print(age + 1)

В строке age = 25 мы сохраняем число 25 под именем age. print(age) выводит содержимое, а print("age") — само слово age.

Имена

Используй латинские буквы, цифры и подчёркивание. Имя не может начинаться с цифры. first_name понятнее, чем x. Python различает age и Age. Не называй переменные print, list или str: это имена полезных встроенных функций.

first_name = "Иван"
last_name = "Петров"
country, city = "Россия", "Казань"
year = 2026
year = year + 1
print(first_name, last_name, year)

Переменную можно связать с новым значением. В year = year + 1 сначала берётся прежний year, к нему прибавляется 1, результат сохраняется под тем же именем.

Встроенные функции

Функция получает данные в скобках и что-то делает или возвращает результат. print печатает, len считает элементы, type определяет тип, abs находит модуль числа, round округляет, min и max выбирают границы, sum складывает.

print(len("Python"))      # 6 символов
print(abs(-7))            # 7
print(round(3.14159, 2))  # 3.14
print(min(4, 8, 2))       # 2
print(max(4, 8, 2))       # 8
print(sum([4, 8, 2]))     # 14

help(print) показывает справку, dir(str) — доступные свойства и методы строк. Не нужно запоминать весь список: пользуйся справкой по мере необходимости.

Преобразование типов

age_text = "25"
age = int(age_text)
price = float("19.90")
label = str(age)
print(age + 1)
print("Мне " + label)
print(int(3.9))  # 3: дробная часть отбрасывается

int превращает подходящий текст в целое число, float — в дробное, str — в текст. int("кот") вызовет ValueError: такой текст не является числом. int("3.9") тоже не сработает; сначала нужен float. Для дробей в коде используют точку, а не запятую.

Операторы: считаем и сравниваем

Арифметика

Оператор — знак, который выполняет действие над значениями. + складывает числа, - вычитает, * умножает, / делит с дробным результатом, // делит с округлением вниз, % возвращает остаток, ** возводит в степень.

print(7 / 2)    # 3.5
print(7 // 2)   # 3
print(-7 // 2)  # -4, округление именно вниз
print(7 % 2)    # 1
print(2 ** 3)   # 8
print((2 + 3) * 4)  # 20

Скобки задают порядок. Без скобок умножение выполняется раньше сложения. Для практических расчётов полезнее понятная формула со скобками, чем головоломка из операторов.

Короткое присваивание

score = 10
score += 5   # то же, что score = score + 5
score -= 2
score *= 3
print(score)  # 39

Есть также /=, //=, %= и **=. Никакого отдельного оператора ++ в Python нет.

Сравнения возвращают bool

print(5 == 5)   # True: равно
print(5 != 3)   # True: не равно
print(5 > 3)    # True: больше
print(5 <= 3)   # False: меньше или равно
age = 20
print(18 <= age < 65)

True означает истину, False — ложь. Одно = присваивает, два == сравнивают. Строки тоже можно сравнивать, но "10" и 10 — разные значения разных типов.

Логика: and, or, not

age = 20
has_ticket = True
print(age >= 18 and has_ticket)  # оба условия истинны
print(age < 18 or has_ticket)    # хотя бы одно истинно
print(not has_ticket)           # отрицание

and — «и», or — «или», not — «не». В логических условиях пустая строка, пустой список, число 0 и None считаются ложными. Остальные непустые значения обычно истинны. and и or могут возвращать сами операнды, а не только True и False.

Принадлежность и идентичность

print("кот" in "котёнок")       # True
print(4 not in [1, 2, 3])      # True
value = None
print(value is None)           # True

in проверяет наличие. is проверяет, один ли это объект в памяти. Для обычного сравнения чисел и строк нужен ==. Проверку отсутствующего значения принято писать is None.

Применение формул

base = 20
height = 10
triangle_area = 0.5 * base * height
radius = 10
circle_area = 3.141592653589793 * radius ** 2
print(triangle_area)
print(circle_area)

Дробные числа хранятся с ограниченной точностью: 0.1 + 0.2 может выглядеть как 0.30000000000000004. Для проверки близости используют math.isclose, а для денежных расчётов — Decimal или целые копейки.

Строки: работаем с текстом

Создание и соединение

Строка str — последовательность символов. Её можно записать в одинарных или двойных кавычках. Тройные кавычки позволяют разместить текст на нескольких строках.

first = "Анна"
last = 'Иванова'
full = first + " " + last
print(full)
print("ха" * 3)
print("Первая строка\nВторая строка")
print("Имя\tВозраст")

\n обозначает перенос строки, \t — табуляцию, \\ — обратную косую черту. Для кавычки внутри строки можно использовать другой вид внешних кавычек или экранирование: "Он сказал: \"Привет\"".

Форматирование

name = "Аня"
age = 25
price = 19.9
print(f"{name}, через год тебе {age + 1}")
print(f"Цена: {price:.2f} руб.")
print("{}: {}".format(name, age))
print("%s: %d" % (name, age))

Для нового кода обычно удобнее f-строка: перед кавычками ставится f, внутри фигурных скобок — выражения. :.2f показывает ровно два знака после точки. Старые способы встречаются в чужом коде, поэтому полезно узнавать их.

Индексы и срезы

word = "Python"
print(word[0])     # P: считаем с нуля
print(word[-1])    # n: последний символ
print(word[0:3])   # Pyt: позиции 0, 1, 2
print(word[2:])    # thon
print(word[:2])    # Py
print(word[::2])   # Pto
print(word[::-1])  # nohtyP

В срезе [начало:конец:шаг] конец не включается. Обращение к несуществующему индексу вызывает IndexError. Срез за пределами строки допустим. Строки неизменяемы: word[0] = "J" не сработает. Нужно создать новую строку.

Методы строк

Метод — функция, которую вызывают через точку у конкретного объекта. Методы ниже возвращают новый результат, исходный текст не меняют.

text = "  Привет, Python!  "
print(text.strip())                 # убирает пробелы с краёв
print(text.lower())                 # нижний регистр
print(text.upper())                 # верхний регистр
print(text.replace("Python", "мир"))
print("яблоко,груша".split(","))    # список частей
print(" / ".join(["Москва", "Казань"]))
print("банан".count("а"))           # 2
print("банан".find("на"))           # 2; -1, если не найдено
print("банан".index("на"))          # ValueError, если не найдено

split разбивает одну строку, join соединяет список строк. strip("ab") удаляет любые символы a и b с обоих краёв, а не конкретное слово ab.

Другие полезные методы

print("python".capitalize())     # Python
print("hello world".title())     # Hello World
print("PyThOn".swapcase())       # pYtHoN
print("main.py".endswith(".py"))
print("https://example.com".startswith("https://"))
print("123".isdigit())
print("abc".isalpha())
print("abc123".isalnum())
print("user_name".isidentifier())
print("abc".islower(), "ABC".isupper())
print("   ".isspace())
print("a-b-a".rfind("a"))         # последний найденный индекс

isdecimal, isdigit и isnumeric проверяют разные классы числовых символов Unicode; они не заменяют попытку преобразования float. expandtabs заменяет табуляции пробелами. Не пытайся запомнить всё за вечер.

Списки: несколько значений вместе

Создание и чтение

Список list — упорядоченная изменяемая коллекция. Представь список покупок: можно дописать продукт, удалить его или заменить. Элементы могут иметь разные типы, хотя часто удобнее хранить однотипные данные.

fruits = ["яблоко", "банан", "груша"]
empty = []
print(len(fruits))
print(fruits[0])
print(fruits[-1])
print(fruits[1:])
fruits[1] = "апельсин"

Индексы и срезы устроены так же, как у строк. В отличие от строки, элемент списка можно заменить. Индекс вне диапазона вызовет IndexError.

Добавление и удаление

items = ["хлеб", "молоко"]
items.append("чай")             # один элемент в конец
items.insert(1, "сыр")          # вставить перед индексом 1
items.extend(["рис", "соль"])   # добавить элементы коллекции
items.remove("молоко")          # удалить первое совпадение
last = items.pop()              # удалить и вернуть последний
del items[0]                    # удалить по индексу
print(items, last)

remove вызовет ValueError, если значения нет. pop на пустом списке вызовет IndexError. clear очищает весь список. append([1, 2]) добавит один вложенный список, extend([1, 2]) добавит два отдельных числа.

Поиск, порядок и сортировка

numbers = [3, 1, 2, 1]
print(2 in numbers)
print(numbers.count(1))  # 2
print(numbers.index(2))  # 2
print(sorted(numbers))  # новый отсортированный список
print(numbers)          # старый порядок
numbers.sort()          # меняет сам список

Множества: только уникальные значения

Зачем нужно множество

Множество set хранит уникальные элементы и удобно для проверки принадлежности. Повторения исчезают. На порядок вывода полагаться нельзя: у множества нет индексов и срезов.

Элементы множества должны быть хешируемыми: подходят строки, числа, многие кортежи. Список или словарь добавить нельзя, потому что они изменяемы и не хешируются.

Изменение

skills = {"Python"}
skills.add("SQL")
skills.update(["Git", "SQL"])
skills.remove("Git")       # ошибка, если элемента нет
skills.discard("Java")     # без ошибки, если нет
print(sorted(skills))

pop удаляет произвольный элемент и возвращает его; на пустом множестве вызывает KeyError. clear очищает множество. del удаляет имя.

Операции как на кругах Эйлера

a = {1, 2, 3}
b = {3, 4}
print(sorted(a | b))  # объединение: 1, 2, 3, 4
print(sorted(a & b))  # пересечение: 3
print(sorted(a - b))  # только в a: 1, 2
print(sorted(a ^ b))  # только в одном из двух: 1, 2, 4

Те же действия доступны как union, intersection, difference и symmetric_difference. Методы intersection_update и difference_update меняют исходное множество. Обычные intersection и difference создают новое.

Подмножество и непересекающиеся наборы

print({1, 2}.issubset({1, 2, 3}))    # True
print({1, 2, 3}.issuperset({1, 2}))  # True
print({1, 2}.isdisjoint({3, 4}))    # True: нет общих
print({1, 2} <= {1, 2, 3})          # подмножество

Строгое подмножество обозначается < и не может быть равно исходному набору. Неизменяемый вариант множества — frozenset.

Функции: даём имя действию

Зачем выносить код в функцию

Если одно действие повторяется, запиши его один раз и вызывай по имени. Функция помогает разбить большую задачу на маленькие понятные части.

def greet(name):
    return f"Привет, {name}!"

message = greet("Аня")
print(message)

def начинает определение. name — параметр: место для будущего значения. "Аня" — аргумент: конкретное значение при вызове. После двоеточия идёт блок с отступом. Пока функцию не вызвали, её тело не выполняется.

return и print — разные вещи

def add(a, b):
    return a + b

result = add(2, 3)
print(result * 10)  # 50

return отдаёт результат вызывающему коду и завершает функцию. print лишь показывает текст на экране. Если return отсутствует, функция возвращает None. Чтобы использовать результат дальше в расчётах, его нужно вернуть.

Аргументы по позиции и имени

def introduce(name, city="Казань"):
    return f"{name}, город {city}"

print(introduce("Аня"))
print(introduce(city="Пермь", name="Илья"))

Значение по умолчанию используется, когда аргумент не передан. Обычные обязательные параметры идут перед параметрами с умолчанием. Именованные аргументы делают вызов понятнее.

Несколько результатов и любое число аргументов

def bounds(numbers):
    return min(numbers), max(numbers)

low, high = bounds([4, 2, 9])
print(low, high)

def total(*numbers):
    return sum(numbers)

def describe(**fields):
    return fields

print(total(1, 2, 3))
print(describe(name="Аня", age=25))

Несколько возвращаемых значений упаковываются в кортеж. *numbers собирает позиционные аргументы в кортеж, **fields — именованные в словарь. При вызове *list распаковывает список в аргументы, **dict — словарь в именованные аргументы.

Область видимости

rate = 10
def calculate(hours):
    pay = hours * rate
    return pay

print(calculate(3))

pay — локальная переменная: существует внутри вызова. rate читается из внешней области. Предпочитай передавать нужные данные параметрами и возвращать результат. Изменение глобального состояния через global делает код сложнее для понимания.

Не используй изменяемое значение по умолчанию

Вместо def add_item(item, items=[]) пиши так:

def add_item(item, items=None):
    if items is None:
        items = []
    items.append(item)
    return items

print(add_item("чай"))
print(add_item("хлеб"))

Значения по умолчанию создаются при определении функции, а не при каждом вызове. Один список по умолчанию неожиданно накапливал бы элементы между вызовами.

Функции, которые работают с функциями

Функция тоже значение

Функцию можно сохранить в переменную, передать другой функции и вернуть как результат. Функцию, которая принимает или возвращает функции, называют функцией высшего порядка.

    return x * 2

    return function(value)

map, filter, reduce

from functools import reduce
numbers = [1, 2, 3, 4]

print(list(filter(lambda x: x % 2 == 0, numbers)))
print(reduce(lambda total, x: total + x, numbers, 0))

map преобразует каждый элемент. filter оставляет те, для которых правило истинно. reduce сворачивает последовательность в один результат, постепенно объединяя накопленное значение с очередным элементом. Здесь sum(numbers) был бы проще. map и filter возвращают итераторы, поэтому для печати всего результата мы превращаем их в list.

Декоратор

Декоратор оборачивает функцию дополнительным поведением: например, пишет сообщение перед вызовом.

from functools import wraps

    @wraps(function)
    def wrapper(*args, **kwargs):
        print("Начинаю")
        return function(*args, **kwargs)
    return wrapper

@announce
def greet(name):
    return f"Привет, {name}"

@announce примерно равнозначно greet = announce(greet). *args и **kwargs передают произвольные аргументы дальше. wraps сохраняет имя и документацию исходной функции. Несколько декораторов применяются снизу вверх.

Обработка исключений и распаковка

Когда ошибку можно обработать

Пользователь может ввести текст вместо числа, файл может отсутствовать. Это ожидаемые ситуации, которые программа должна объяснить. try запускает код, except обрабатывает конкретную ошибку.

text = "не число"
try:
    number = int(text)
except ValueError:
    print("Введите целое число")
else:
    print(number * 2)
finally:
    print("Попытка закончена")

else выполняется, если блок try завершился без исключения. finally выполняется при выходе из try независимо от успеха; это место для освобождения ресурсов. Для файлов проще и надёжнее with, который изучим в главе 19.

Лови то, что понимаешь

try:
    result = 10 / 0
except ZeroDivisionError as error:
    print("На ноль делить нельзя:", error)

Не оборачивай всю программу в except: pass. Так можно скрыть собственную ошибку. В except (ValueError, TypeError): можно перечислить несколько ожидаемых исключений. Размещай в try небольшой участок, чтобы было ясно, какое действие обрабатывается.

Поднимаем исключение сами

def average(numbers):
    if not numbers:
        raise ValueError("Нужен хотя бы один элемент")
    return sum(numbers) / len(numbers)

Регулярные выражения: ищем текст по шаблону

Когда они нужны

Если нужен поиск буквального слова, достаточно in, find или replace. Регулярные выражения полезны, когда ищем структуру: последовательность цифр, повторение, несколько вариантов написания.

import re
text = "Заказ 15: 3 книги за 1200 рублей"
print(re.findall(r"\d+", text))

r перед кавычками создаёт сырую строку: обратные косые черты передаются регулярному выражению без дополнительного экранирования Python.

Основные операции

import re
text = "Python и python"
found = re.search(r"python", text, flags=re.IGNORECASE)
if found:
    print(found.group(), found.span())
print(re.match(r"Python", text).group())
print(re.fullmatch(r"\d+", "123") is not None)
print(re.findall(r"python", text, flags=re.I))
print(re.sub(r"python", "Пайтон", text, flags=re.I))
print(re.split(r"[,;]\s*", "чай, кофе; вода"))

search ищет в любом месте. match — только в начале. fullmatch требует совпадения всей строки. Если совпадения нет, результат — None: нельзя сразу вызывать group без проверки. findall возвращает все совпадения, sub заменяет, split разбивает.

Словарь знаков

- . — любой символ, обычно кроме перевода строки.

- \d — цифра, \w — буква, цифра или подчёркивание, \s — пробельный символ.

- \D, \W и \S — противоположные классы.

- [abc] — один из перечисленных символов, [a-z] — диапазон.

- [^0-9] — любой символ, кроме указанных.

- * — ноль или больше повторов, + — один или больше, ? — ноль или один.

- {3} — ровно три повтора, {2,4} — от двух до четырёх.

- ^ — начало строки, $ — конец; | — выбор варианта.

Представь анкету: у каждого человека есть имя и возраст. Класс описывает, какие данные и действия связаны с человеком. Объект хранит данные одного конкретного человека.

Наследование

class Person:
    def __init__(self, name):
        self.name = name

    def greet(self):
        return f"Привет, я {self.name}"

class Student(Person):
    def __init__(self, name, course):
        super().__init__(name)
        self.course = course

    def greet(self):
        return f"{super().greet()}, изучаю {self.course}"

student = Student("Аня", "Python")
print(student.greet())
print(isinstance(student, Person))

Student наследует поведение Person и может переопределять методы. super обращается к реализации базового класса по порядку разрешения методов. Наследование полезно для отношения «является разновидностью». Если объект просто использует другой объект, часто проще хранить его как атрибут.

Сбор данных со страниц

Что такое web scraping

Это извлечение нужных данных из HTML-страницы. Браузер показывает красивую страницу, а программа обычно получает её исходный HTML. Если сайт строит содержимое через JavaScript, простой HTTP-запрос может не увидеть нужные данные.

Начнём без интернета

В Python есть встроенный HTMLParser. Он позволяет понять идею, не устанавливая ничего.

from html.parser import HTMLParser

class HeadingReader(HTMLParser):
    def __init__(self):
        super().__init__()
        self.inside = False
        self.parts = []

    def handle_starttag(self, tag, attrs):
        if tag == "h1":
            self.inside = True

    def handle_endtag(self, tag):
        if tag == "h1":
            self.inside = False

    def handle_data(self, data):
        if self.inside:
            self.parts.append(data)

reader = HeadingReader()
reader.feed("<h1>Учим Python</h1><p>Начинаем</p>")
print("".join(reader.parts))

Это упрощённый обработчик заголовков, а не универсальный парсер всех случаев вложенной разметки.

Статистика и NumPy

Что рассказывают числа

Среднее — сумма значений, делённая на их количество. Медиана — значение в середине отсортированного набора; при чётном количестве берут среднее двух центральных. Мода — наиболее частое значение. Размах — максимум минус минимум.

import statistics as stats
ages = [19, 20, 20, 21, 40]
print(stats.mean(ages))        # 24
print(stats.median(ages))      # 20
print(stats.multimode(ages))   # [20]
print(max(ages) - min(ages))   # 21

Возраст 40 заметно сдвигает среднее, но почти не влияет на медиану. Поэтому одно среднее не всегда хорошо описывает группу. На пустом наборе среднее не определено.

Разброс

import statistics as stats
values = [2, 4, 4, 4, 5, 5, 7, 9]
print(stats.pvariance(values))  # дисперсия совокупности
print(stats.pstdev(values))     # стандартное отклонение: 2
print(stats.variance(values))   # выборочная дисперсия

Дисперсия показывает средний квадрат отклонения от среднего. Стандартное отклонение — квадратный корень дисперсии, выраженный в исходных единицах. pvariance делит на N, variance — на N - 1 и требует хотя бы двух значений. Выбирай определение по смыслу данных.

NumPy: массивы вместо списков

Установи numpy в выбранное окружение через python -m pip install numpy. Следующие блоки требуют этот пакет.

import numpy as np
a = np.array([1, 2, 3, 4])
print(a * 2)         # каждый элемент умножен на 2
print(a + 10)
print(a.mean(), a.min(), a.max())
print(a.shape, a.ndim, a.dtype)
print(a[a > 2])      # фильтр по булевой маске

Список [1, 2] * 2 повторяется, массив np.array([1, 2]) * 2 умножается поэлементно. dtype — тип элементов; shape — размеры по осям; ndim — число осей. Массив обычно хранит однотипные данные.

Браузер отправляет HTTP-запрос по URL. Сервер выбирает обработчик и возвращает ответ: HTML, JSON, файл или сообщение об ошибке. Python часто используется на сервере. HTML описывает структуру страницы, CSS — внешний вид, JavaScript — поведение в браузере.

MongoDB: храним данные между запусками

База данных вместо временных переменных

После завершения программы переменные исчезают. База данных сохраняет записи и помогает искать, обновлять и удалять их. В MongoDB записи называются документами и похожи на словари. Документы объединяются в коллекции, коллекции — в базы данных. Внутренний формат BSON поддерживает больше типов, чем обычный JSON.

Сначала модель на обычном списке

students = [
    {"name": "Аня", "age": 25},
    {"name": "Илья", "age": 19},
]
adults = [person for person in students if person["age"] >= 21]
print(adults)

Это не база данных: изменения исчезнут после запуска. Но смысл фильтрации такой же, как у запроса. Чтобы подготовиться к реальной MongoDB, разберись с документами и условиями на этом маленьком примере.

Подключение

Нужен отдельный сервер MongoDB: локальный или облачный Atlas, а также пакет pymongo. Он не входит в комплект книги. Строка подключения зависит от твоей установки и не должна попадать в публичный код.

import os
from pymongo import MongoClient
client = MongoClient(os.environ["MONGODB_URI"], serverSelectionTimeoutMS=3000)
database = client["python_study"]
collection = database["students"]
print(client.admin.command("ping"))
client.close()

Задай MONGODB_URI в окружении перед запуском отдельного файла. Не вставляй пароль в репозиторий или заметки курса. Для локальной установки строка часто начинается с mongodb://localhost:27017/, но конкретные настройки нужно брать из собственной установки.

CRUD: создать, прочитать, обновить, удалить

Следующие фрагменты предполагают, что collection уже получена из открытого подключения выше. Они изменяют выбранную коллекцию; используй отдельную учебную базу.

result = collection.insert_one({"name": "Аня", "age": 25})
print(result.inserted_id)
person = collection.find_one({"_id": result.inserted_id})
print(person)
collection.update_one({"_id": result.inserted_id}, {"$set": {"age": 26}})
collection.delete_one({"_id": result.inserted_id})

MongoDB обычно создаёт уникальный _id типа ObjectId. insert_many добавляет несколько документов. update_many и delete_many действуют на все совпадения. Пустой фильтр {} означает все документы: особенно внимательно относись к операциям удаления.

Фильтры, поля, сортировка и лимит

query = {"age": {"$gte": 18, "$lt": 30}}
for person in collection.find(query, {"name": 1, "age": 1, "_id": 0}).sort("age", 1).limit(5):
    print(person)

$gte означает ≥, $gt — >, $lte — ≤, $lt — <, $in — принадлежность набору. Проекция задаёт поля ответа. sort(..., 1) сортирует по возрастанию, -1 — по убыванию. find возвращает курсор, который перебирают. Для часто используемых поисковых полей создают индексы, но они требуют дополнительного места и времени при записи.

Практика

1. На списке словарей реализуй добавление, поиск по имени и изменение возраста.

2. При наличии MongoDB повтори действия в отдельной учебной коллекции.

3. Добавь фильтр по диапазону возраста и сортировку.

API: программы общаются с программами

Что такое API

API — договор о способах обращения к программе. HTTP API определяет адреса, методы, формат запросов и ответов. Если сайт — интерфейс для человека, то API часто служит интерфейсом для другой программы.

Представь сервис книг. GET /books получает список, GET /books/7 — одну книгу, POST /books создаёт новую, PATCH /books/7 меняет часть полей, DELETE /books/7 удаляет запись. PUT обычно заменяет представление ресурса целиком. Это распространённые соглашения, а точные правила задаёт документация конкретного API.

Статусы HTTP

- 200 OK — запрос выполнен.

- 201 Created — создан новый ресурс.

- 204 No Content — успешно, тела ответа нет.

- 400 Bad Request — запрос некорректен.

- 401 Unauthorized — нужна действительная аутентификация.

- 403 Forbidden — доступ запрещён.

- 404 Not Found — ресурс не найден.

- 429 Too Many Requests — слишком много запросов.

- 500 Internal Server Error — ошибка сервера.

JSON и проверка данных

import json
response_text = '{"books": [{"id": 1, "title": "Python"}]}'
data = json.loads(response_text)
for book in data["books"]:
    print(book["id"], book["title"])

Успешный HTTP-ответ ещё не гарантирует нужную структуру данных. Проверяй типы и обязательные поля. Не все ответы являются JSON: иногда сервер присылает HTML-страницу ошибки.

Запрос из Python

При установленном requests и доступе к сети:

import requests
response = requests.get(
    "https://httpbin.org/get",
    params={"topic": "python", "page": 1},
    timeout=5,
)
response.raise_for_status()
data = response.json()
print(data["args"])

params формирует параметры URL. Для POST с JSON используют json={...}. Заголовки передаются через headers={...}. API-ключи берут из переменных окружения, а не вписывают в публичный файл. Для учебного примера httpbin ключ не нужен.

Пагинация и ограничения

Большие списки обычно возвращают частями: страницами или курсорами. Пока документация не говорит об окончании, нужно запрашивать следующую часть. Не угадывай формат курсора. При 429 учитывай Retry-After. Повторение POST без защиты от дубликатов может создать несколько записей.

2. Разбери JSON с книгами и выведи только названия.

Создаём своё API

Минимальный сервис задач

Установи Flask в виртуальное окружение. Сохрани следующий код в отдельный файл api_app.py и запусти в терминале через python api_app.py. В книге длительные серверы автоматически останавливаются, поэтому этот пример запускается отдельно.

from flask import Flask, jsonify, request

app = Flask(__name__)
tasks = {}
next_id = 1

@app.get("/tasks")
def list_tasks():
    return jsonify(list(tasks.values()))

@app.get("/tasks/<int:task_id>")
def get_task(task_id):
    task = tasks.get(task_id)
    if task is None:
        return jsonify(error="Задача не найдена"), 404
    return jsonify(task)

@app.post("/tasks")
def create_task():
    global next_id
    data = request.get_json(silent=True)
    if not isinstance(data, dict):
        return jsonify(error="Нужен JSON-объект"), 400
    title = data.get("title")
    if not isinstance(title, str) or not title.strip():
        return jsonify(error="Нужно непустое текстовое title"), 400
    task = {"id": next_id, "title": title.strip(), "done": False}
    tasks[next_id] = task
    next_id += 1
    return jsonify(task), 201

@app.patch("/tasks/<int:task_id>")
def update_task(task_id):
    if task_id not in tasks:
        return jsonify(error="Задача не найдена"), 404
    data = request.get_json(silent=True)
    if not isinstance(data, dict) or not isinstance(data.get("done"), bool):
        return jsonify(error="Нужно логическое поле done"), 400
    tasks[task_id]["done"] = data["done"]
    return jsonify(tasks[task_id])

@app.delete("/tasks/<int:task_id>")
def delete_task(task_id):
    if task_id not in tasks:
        return jsonify(error="Задача не найдена"), 404
    del tasks[task_id]
    return "", 204

if __name__ == "__main__":
    app.run(host="127.0.0.1", port=5000)

Пример хранит данные в памяти одного процесса. При перезапуске они исчезнут. Он предназначен для локального изучения, не для общей базы в многопроцессном сервере. Позже tasks можно заменить коллекцией MongoDB или таблицей SQLite.

Как проверить

Браузер умеет открыть GET http://127.0.0.1:5000/tasks. Для POST и PATCH удобен отдельный клиент на Python:

import requests
base = "http://127.0.0.1:5000"
created = requests.post(base + "/tasks", json={"title": "Пройти главу"}, timeout=3)
created.raise_for_status()
task = created.json()
print(task)
updated = requests.patch(base + f"/tasks/{task['id']}", json={"done": True}, timeout=3)
print(updated.status_code, updated.json())

Клиент запускается после старта сервера. Проверяй не только успешный путь: отправь пустое название, число вместо текста, неизвестный id, неверный тип done. Хороший API объясняет ошибку и возвращает соответствующий статус.

Подсказка

Проверь isinstance(title, str), затем title.strip().

Решение
def validate(data):
    title = data.get("title")
    if isinstance(title, str) and title.strip():
        return 201
    return 400

print(validate({"title": "Учить Python"}))
print(validate({"title": "   "}))

Проект: личный список задач

Сделай консольную программу, которая позволяет добавить задачу, показать список, отметить задачу выполненной и удалить её. Данные должны сохраняться в tasks.json. Библиотек сверх стандартной не нужно.

Начни с модели данных:

tasks = [
    {"id": 1, "title": "Повторить функции", "done": False},
    {"id": 2, "title": "Решить три задачи", "done": True},
]
for task in tasks:
    mark = "✓" if task["done"] else "○"
    print(f"{mark} {task['id']}. {task['title']}")

Затем добавь функции add_task, complete_task, delete_task, load_tasks и save_tasks. Каждая должна заниматься одним понятным действием. Для нового id используй max существующих id плюс 1, а не просто длину списка: после удаления длина может совпасть со старым id.

Делай по одному шагу

1. Покажи заранее записанный список.

2. Добавь новую задачу в память.

3. Реализуй поиск по id и отметку done.

4. Сохрани в JSON через json и pathlib.

5. Загрузи из файла при запуске. При отсутствии файла начни с пустого списка; повреждённый файл не перезаписывай молча.

6. Добавь меню while, которое заканчивается по команде выхода.

7. Проверь неправильные команды, пустое название и неизвестный id.

Для интерактивного меню удобнее отдельный терминал: встроенная практика получает заранее подготовленный ввод и ограничивает время выполнения. Сохрани свой код через кнопку «Сохранить .py» и запусти его самостоятельно.
